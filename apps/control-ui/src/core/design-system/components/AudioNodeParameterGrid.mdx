## Playground·API·기본값

<a href="/?path=/story/core-playgrounds-audionodeparametergrid--playground" target="_top">AudioNodeParameterGrid Playground 열기</a>. Controls는 실제 공개 props를 전달합니다. 구현 기본값은 아래 API 표와 소스 대조 계약을 따르며, Playground의 args는 재현용 입력입니다.

연속된 노브는 최대 3열로 묶고, 선택형·정밀 입력·슬라이더는 한 행씩 배치합니다. 값은 Feature가 확인한 readback을 따릅니다.

<ArgTypes of={Api.Playground} exclude={["className","classNames","style","styles","vars","unstyled","color","c","size","radius","variant","component","renderRoot","dangerouslySetInnerHTML"]} />

API 표의 *는 필수 입력입니다. Default의 —는 선언된 기본값이 없다는 뜻이며, 파생값·fallback과 초기 상태는 위 소스 대조 계약에 명시합니다.

속성은 Playground의 Controls에서 변경합니다. Source는 현재 JSX를, 위의 실행 예제 전체 코드는 실제 상태 갱신·이벤트·슬롯 구성을 보여줍니다.
