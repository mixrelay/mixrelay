## Playground·API·주요 속성

<a href="/?path=/story/core-controls-textfield--playground" target="_top">Playground 열기</a>에서 입력과 Controls의 value를 변경합니다. 입력 중에는 Storybook preview의 로컬 상태로 값을 보존하고 blur에서 args를 갱신합니다. Controls 변경은 입력에 바로 반영합니다. controlled 값은 input 이벤트를 상태에 돌려보내고, 초기값만 필요한 필드는 defaultValue를 사용합니다. 두 소유 방식을 함께 전달하지 않습니다.

<Canvas of={Api.Playground} story={{ inline: false, height: 220 }} sourceState="hidden" />
<ArgTypes of={Api.Playground} include={['label', 'value', 'description', 'error', 'type', 'disabled', 'readOnly', 'required', 'onChange']} />

readOnly는 읽기·선택·복사를 허용하고 disabled는 현재 편집을 막습니다. 요청 실패는 작성한 값을 지우지 않고 오류를 입력과 연결합니다. 암호 표시 버튼은 값과 편집을 보존합니다.
