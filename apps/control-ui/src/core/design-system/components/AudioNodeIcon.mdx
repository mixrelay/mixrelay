## Playground·API·기본값

<a href="/?path=/story/core-playgrounds-audionodeicon--playground" target="_top">AudioNodeIcon Playground 열기</a>. Controls는 실제 공개 props를 전달합니다. 구현 기본값은 아래 API 표와 소스 대조 계약을 따르며, Playground의 args는 재현용 입력입니다.

발견된 앱·플랫폼 아이콘(iconUrl)이 우선이며, 없거나 불러오지 못한 경우에만 icon 종류의 공통 기호를 표시합니다.

<Canvas of={Api.Playground} story={{ inline: false, height: 320 }} sourceState="hidden" />
<ArgTypes of={Api.Playground} exclude={["className","classNames","style","styles","vars","unstyled","color","c","size","radius","variant","component","renderRoot","dangerouslySetInnerHTML"]} />

API 표의 *는 필수 입력입니다. Default의 —는 선언된 기본값이 없다는 뜻이며, 파생값·fallback과 초기 상태는 위 소스 대조 계약에 명시합니다.

속성은 Playground의 Controls에서 변경합니다. Source는 현재 JSX를, 위의 실행 예제 전체 코드는 실제 상태 갱신·이벤트·슬롯 구성을 보여줍니다.
