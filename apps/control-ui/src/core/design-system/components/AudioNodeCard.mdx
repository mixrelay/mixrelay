## Playground·API·기본값

<a href="/?path=/story/core-playgrounds-audionodecard--playground" target="_top">AudioNodeCard Playground 열기</a>. Controls는 실제 공개 props를 전달합니다. 구현 기본값은 아래 API 표와 소스 대조 계약을 따르며, Playground의 args는 재현용 입력입니다.

샘플 callback은 Actions에 기록하며 제품 요청을 실행하지 않습니다.

API 표의 *는 필수 입력입니다. Default의 —는 선언된 기본값이 없다는 뜻이며, 파생값·fallback과 초기 상태는 위 소스 대조 계약에 명시합니다.

속성은 Playground의 Controls에서 변경합니다. Source는 현재 JSX를, 위의 실행 예제 전체 코드는 실제 상태 갱신·이벤트·슬롯 구성을 보여줍니다.

## 장치 앱 활동

`deviceAppActivity`는 채널 요약 뒤에 방향, 최대 세 앱 아이콘, `+N`을 표시한다. Feature가 native UID로 합친 관찰값과 번역 문구를 공급한다. source는 playing, sink는 recording만 표시하고 Off·Mute·미터·선택으로 활동을 추정하지 않는다.

전체 목록은 바깥 노드의 기존 키보드 설명에 추가되며 같은 노드의 focus tooltip으로 표시된다. 읽기 전용 아이콘·overflow는 Tab 정지점을 추가하지 않는다. 확인된 빈 응답은 “앱 없음”, 미지원·실패·3초 경과는 확인 불가로 구분한다.
