이름 입력·설명·오류 다음에 취소와 확정 버튼을 우측 하단에 둡니다. 제목줄에는 중복 닫기 버튼을 두지 않습니다. 초기 필드 → 취소 → 확정 순서로 Tab 이동하고, Escape 취소 후 원래 조작으로 돌아갑니다.

표시 이름은 저장된 별칭만 initialName으로 전달합니다. 별칭이 없으면 빈 입력에 placeholder로 원래 이름을 보여 줍니다. nameLabel은 유지하며 placeholder를 접근성 이름이나 실제 저장 값으로 사용하지 않습니다. 기본 이름 복원은 allowEmpty로, 선택에 필요한 추가 정보만 description으로 전달합니다.

## Playground·API·기본값

<a href="/?path=/story/core-playgrounds-namedialog--playground" target="_top">NameDialog Playground 열기</a>. Controls는 실제 공개 props를 전달합니다. 구현 기본값은 아래 API 표와 소스 대조 계약을 따르며, Playground의 args는 재현용 입력입니다.

initialName은 최초 mount의 초기값입니다. Controls에서 바꾼 뒤 닫고 다시 열면 새 초기값을 사용합니다.

API 표의 *는 필수 입력입니다. Default의 —는 선언된 기본값이 없다는 뜻이며, 파생값·fallback과 초기 상태는 위 소스 대조 계약에 명시합니다.

속성은 Playground의 Controls에서 변경합니다. Source는 현재 JSX를, 위의 실행 예제 전체 코드는 실제 상태 갱신·이벤트·슬롯 구성을 보여줍니다.

## 표시 이름 초기화

기존 생성은 빈 이름을 거부합니다. 표시 이름 편집은 `allowEmpty=true`, `maxLength=128`을 전달합니다. 별칭이 없으면 입력은 빈 값이고 placeholder만 원래 이름입니다. 빈 제출은 소비자가 원래 이름으로 복원합니다. 초기값은 mount에서 읽으므로 외부 표시 메타데이터가 갱신돼도 작성 중인 값은 유지합니다.
