## Playground·API·주요 속성

실제 ActionButton의 지원 속성을 조작하는 <a href="/?path=/story/core-controls-actionbutton--playground" target="_top">Playground 열기</a>. iframe 예시 옆의 정적 속성 표는 실행 값을 바꾸지 않습니다. Playground 화면의 Controls에서 값을 바꾸고 코드를 확인합니다.

<Canvas of={Api.Playground} story={{ inline: false, height: 180 }} sourceState="hidden" />
<ArgTypes of={Api.Playground} include={['children', 'tone', 'density', 'emphasis', 'stretch', 'align', 'loading', 'disabled', 'onClick']} />

strong은 해당 폼의 최종 제출, quiet는 일반 명령에 사용합니다. loading은 현재 제출의 중복 실행을 막으며 제출 결과를 대신 표시하지 않습니다. 실제 조합과 키보드 상태는 아래 예시를 함께 확인합니다.

기본 높이는 regular 28px·compact 24px입니다. 좁은 폭의 긴 명령은 부모 폭 안에서 줄바꿈하며 높이가 늘어납니다. 이름을 자르거나 모달에 가로 스크롤을 만들지 않습니다.
