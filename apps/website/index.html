하나의 작업 공간

듣고, 다듬고, 남기는 흐름을
한 그래프 안에.

01 / ROUTE

필요한 소리를 모으기

실행 중인 앱, 오디오 입력 장치, MixRelay 가상 장치를 소스로 놓고 원하는 출력에 연결합니다.

02 / PROCESS

경로마다 다듬기

내장 컴프레서와 리미터, 현재 검색된 오디오 플러그인을 신호 흐름에 배치합니다.

03 / RECORD

믹스를 파일로 기록

레코더에서 폴더, WAV 샘플레이트와 비트 심도를 정하고 녹음·일시정지·재개·정지를 제어합니다.

04 / STREAM DECK

자주 쓰는 제어를 버튼에

macOS Stream Deck 플러그인에서 전원, 음소거, 볼륨과 녹음 동작을 그래프의 노드에 연결합니다.

플러그인 형식, 채널 연결과 장치 사용 가능 여부는 운영체제와 각 장치·플러그인에 따라 달라질 수 있습니다. 가상 장치는 신호를 자동 전달하거나 시스템 기본 장치를 바꾸지 않습니다.

이용 방식

설치는 무료.
먼저 14일 사용해 보세요.

첫 실행일부터 14일 평가판이 시작됩니다. 이후 계속 사용하려면 유료 라이선스가 필요합니다. 영구 무료 기능 요금제는 없습니다.

유료 라이선스를 활성화하거나 온라인으로 성공적으로 확인하면, 그 시점부터 최대 30일간 오프라인으로 사용할 수 있습니다. 앱 실행이나 실패한 확인 요청은 기간을 연장하지 않습니다.
