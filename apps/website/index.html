사용 흐름 살펴보기 ↗

제품과 안내서의 사전 공개 초안입니다. 현재 다운로드와 구매는 제공하지 않습니다.

하나의 작업 공간

듣고, 다듬고, 남기는 흐름을
한 그래프 안에.

01 / ROUTE

필요한 소리를 모으기

실행 중인 앱, 오디오 입력 장치, MixRelay 가상 장치를 소스로 놓고 원하는 출력에 연결합니다.

02 / PROCESS

경로마다 다듬기

내장 컴프레서와 리미터, 현재 검색된 오디오 플러그인을 신호 흐름에 배치합니다.

03 / RECORD

믹스를 파일로 기록

녹음기에서 폴더, WAV 샘플레이트와 비트 심도를 정하고 녹음·일시정지·재개·정지를 제어합니다.

04 / STREAM DECK

자주 쓰는 제어를 버튼에

macOS Stream Deck 플러그인에서 전원, 음소거, 볼륨과 녹음 동작을 그래프의 노드에 연결합니다.

플러그인 형식, 채널 연결과 장치 사용 가능 여부는 운영체제와 각 장치·플러그인에 따라 달라질 수 있습니다. 가상 장치는 신호를 자동 전달하거나 시스템 기본 장치를 바꾸지 않습니다.

이용 방식

설치는 무료.
기간 제한 없이 사용해 보세요.

무료 모드는 기간 제한 없이 기본 라우팅과 녹음을 제공합니다. 그래프·입력·출력·채널 매핑·플러그인·녹음에는 기능 한도가 있으며, 유료 라이선스로 추가 기능을 사용할 수 있습니다. 무료 Driver의 최대 64채널과 장치 설정은 구매 인증 없이 사용할 수 있습니다.

유료 인증을 해제한 기기에서도 무료 기능은 계속 사용할 수 있습니다. 이전 기기의 인증을 해제한 뒤 새 기기에서 같은 라이선스 키로 활성화할 수 있습니다.

구매 후 30일 이내에는 이유를 묻지 않고 전액 환불합니다. 지원 문의는 한국의 영업일 기준 2일 이내 첫 응답을 목표로 합니다.
