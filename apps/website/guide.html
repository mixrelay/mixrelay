안내서

처음 시작하기 그래프와 연결 프로세서와 제어 녹음하기 Stream Deck 작업 공간과 종료 무료 모드와 라이선스

MIXRELAY / GUIDE

사용 안내서

그래프 구성부터 녹음과 라이선스까지, 자주 필요한 조작을 간단히 정리했습니다.

제품과 안내서의 사전 공개 초안입니다. 설치 파일은 아직 제공하지 않습니다.

01

처음 시작하기

  1. 왼쪽 그래프 목록에서 새 그래프를 누르고 이름을 입력한 뒤 생성합니다.
  2. 캔버스의 노드 추가에서 소스, 프로세서, 출력을 선택합니다.
  3. 노드의 출력 포트에서 입력 포트로 끌어 케이블을 연결합니다.

그래프 목록에서 다른 그래프를 선택하면 편집 대상이 바뀝니다. 그래프를 전환해도 다른 그래프의 오디오 처리는 계속 실행됩니다.

그래프 이름은 화면 위쪽에서 바꿀 수 있고 편집과 배치는 자동 저장됩니다. 저장 실패 시 화면에 경고가 표시됩니다.

02

그래프와 연결

소스에는 실행 중인 앱, 오디오 입력 장치와 MixRelay 가상 장치 입력이 있습니다. 출력에서는 가상 장치, 오디오 출력 장치, 레코더를 선택할 수 있습니다.

MixRelay 가상 장치는 신호를 다른 장치로 자동 전달하거나 시스템 기본 장치를 바꾸지 않습니다. 필요한 입력·출력 노드를 그래프에 배치해 직접 연결하세요.

macOS/Linux 가상 장치는 입력·출력 방향별 1–64채널을 지원합니다. 가상 장치의 Options에는 장치가 지원하는 채널 수가 표시됩니다. 공통 DSP·미터·플러그인은 64채널 처리를 유지하며, 물리 장치는 해당 장치가 제공하는 채널 구성을 사용합니다.

노드나 케이블을 선택해 Delete 또는 Backspace를 누르면 제거됩니다. 오른쪽 클릭 메뉴에서도 삭제할 수 있습니다. 그래프 삭제는 해당 그래프의 오디오 처리와 녹음을 멈추며 되돌릴 수 없지만, 이미 저장한 작업 공간 파일은 삭제하지 않습니다.

03

프로세서와 제어

노드 추가 → 프로세서에서 내장 컴프레서·리미터와 현재 검색된 오디오 플러그인을 선택합니다. 플러그인 설치 위치를 추가하거나 오디오 이펙트 다시 스캔으로 목록을 갱신할 수 있습니다.

지원 형식과 채널 연결은 운영체제와 플러그인의 채널 레이아웃에 따라 달라집니다. 지원되지 않는 형식이나 연결은 적용되지 않습니다.

전원 제어가 표시되는 노드는 전원 버튼으로 처리를 켜거나 끌 수 있습니다. 끈 노드는 바이패스되지 않고 신호 경로에서 제외됩니다. 음소거는 처리를 유지하면서 소리만 끄는 별도 제어이며, 지원하는 노드에 표시됩니다. Options에서 노드가 제공하는 레벨·게인, 채널, 장치 설정이나 플러그인 파라미터를 조정합니다.

04

녹음하기

  1. 노드 추가 → 출력 → 레코더를 선택해 그래프에 추가합니다.
  2. 레코더의 Options에서 채널 수, 저장 폴더, WAV 샘플레이트와 비트 심도를 설정합니다.
  3. 녹음으로 시작하고, 필요하면 일시정지 후 재개하거나 정지합니다.

녹음 중이거나 일시정지 중에는 설정을 바꿀 수 없습니다. 먼저 정지한 뒤 변경하세요.

일시정지 후 재개하면 같은 파일에 이어서 녹음합니다. 일시정지한 구간은 파일에서 빠지며 무음으로 채우지 않습니다. 10초 녹음 후 5초 일시정지하고 다시 10초 녹음하면 파일 길이는 20초입니다. 녹음 시간 제한도 파일에 기록된 시간을 기준으로 합니다.

05

Stream Deck

macOS Stream Deck 플러그인에서 전원, 음소거, 볼륨, 녹음 동작을 추가한 뒤 대상 그래프와 해당 동작을 지원하는 노드를 선택합니다. 녹음 동작은 레코더 노드만 목록에 표시됩니다.

볼륨 버튼은 증가·감소 방향과 조절 단위를 설정합니다. Stream Deck+ 다이얼은 회전으로 같은 단위만큼 볼륨을 조절하고, 다이얼을 누르면 음소거합니다(대상 노드가 음소거를 지원하는 경우).

녹음 동작에서 녹음·일시정지·정지를 선택합니다. 저장 폴더와 형식은 MixRelay 레코더 설정을 사용하며 Stream Deck 속성창에서는 읽기 전용입니다.

06

작업 공간과 종료

앱 메뉴의 파일에서 새 작업 공간, 열기, 저장, 다른 이름으로 저장을 선택합니다. 작업 공간 파일 확장자는 .mix입니다. 새 작업 공간이나 파일을 열면 현재 내용을 교체할지 묻습니다.

앱 하단 또는 MixRelay Driver 상태 메뉴에서 일시정지하면 모든 그래프의 라우팅·오디오 처리와 진행 중인 녹음이 멈춥니다. 앱과 Driver는 계속 실행되며 설정과 녹음 파일은 유지됩니다. 재개하면 현재 소리부터 다시 처리하고 같은 파일에 녹음을 이어 씁니다. 녹음기에서 따로 일시정지한 파일, 중지한 파일과 삭제한 녹음기는 자동으로 재개하지 않습니다. 전체 일시정지 중에도 녹음기의 정지로 파일을 마무리할 수 있습니다.

앱 창을 닫거나 앱을 종료해도 MixRelay Driver는 오디오 처리를 계속합니다. Driver 상태 메뉴의 MixRelay 열기로 앱을 다시 열 수 있습니다. Driver 상태 메뉴에서 종료하면 오디오 처리를 끝내고 열려 있는 녹음 파일을 마무리합니다.

MixRelay에 연결된 실행부에서는 일시정지해도 가상 장치가 유지됩니다. 그래프 실행부를 사용하지 않는 독립 Driver 관리 모드에서는 가상 장치를 잠시 비활성화합니다. OS의 장치 목록에서 사라졌다가 재개하면 기존 ID·이름·형식으로 복원됩니다.

07

무료 모드와 라이선스

무료 모드는 기간 제한 없이 사용할 수 있습니다. 그래프 1개, 입력 노드 2개, 출력 장치 2개, 가상 장치 1개, Driver 채널 매핑 총 4개, 외부 플러그인 2개, 레코더 1개·최대 2채널·녹음당 2시간을 제공합니다. 무료 그래프 1개와 그 채널 매핑은 저장·불러오기할 수 있습니다. 장치 이름 변경은 유료 기능입니다. 무료 Driver의 최대 64채널과 장치 설정은 이 앱의 기능 한도와 별개입니다.

화면 왼쪽 아래의 버전·인증 상태를 누르면 라이선스 화면이 열립니다. 구매 후 라이선스 키와 기기 이름을 입력해 활성화하고, 온라인 확인으로 인증 상태를 다시 확인할 수 있습니다. 이전 기기의 인증을 해제한 뒤 새 기기에서 같은 키로 활성화할 수 있으며, 인증을 해제한 기기에서도 무료 기능은 계속 사용할 수 있습니다.

오프라인으로 사용 중인 컴퓨터는 원격으로 인증 상태를 갱신할 수 없습니다. 통신 실패만으로 진행 중인 재생·녹음을 중단하지 않습니다. 오프라인 인증은 마지막 온라인 인증 성공부터 30일간 유효합니다. 활성화 기기 수와 온라인 자동 확인 주기는 판매 시작 전에 확정하여 안내합니다.

구매 후 30일 이내에는 이유를 묻지 않고 전액 환불합니다. 지원 문의는 한국의 영업일 기준 2일 이내 첫 응답을 목표로 합니다.

구매 스토어와 구매 링크는 아직 준비되지 않았습니다. 가격도 확정되지 않았으며, 공개 전까지 이 사이트에서 라이선스를 구매할 수 없습니다.
