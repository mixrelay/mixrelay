Stream Deck 外掛程式

在 macOS 上透過 Stream Deck 控制音訊圖節點。

發佈前草稿。目前尚未提供公開下載或購買。本手冊說明目前原始碼建置版本的行為；在下文所列環境中，仍須驗證安裝後的實際行為。

本頁內容

  • 需求與設定
  • 按鍵、旋鈕與錄音

01

需求與設定

需要 macOS 14.2 或以上版本、Stream Deck 6.6 或以上版本，且 MixRelay 正在執行。不提供 Linux Stream Deck 支援。外掛程式使用私有本機連線，無須帳號、區域網路配對或公開 HTTP 服務。

  1. 官方外掛程式套件可用後，用 Stream Deck 開啟其 .streamDeckPlugin 檔案。目前尚未提供公開下載。
  2. 加入一個 MixRelay 的 電源、靜音、音量 或 錄音 動作。
  3. 在屬性檢查器中，選擇目標音訊圖和支援該動作的節點。

請保持 MixRelay 背景音訊運作，可以關閉編輯器視窗。節點被刪除後，必須手動重新指定目標。失敗或斷線時的指令不會排入佇列等待稍後執行。

02

按鍵、旋鈕與錄音

電源 開啟或關閉節點處理。靜音 在保持處理的同時使輸出靜音。節點關閉時，必須先開啟電源，其他控制項才能操作它。

對於 音量 按鈕，選擇增加或減少，以及 0.5、1、2 或 3 dB 的步進值。旋轉 Stream Deck + 旋鈕時，音量依同樣的步進值變化。如果目標支援靜音，按下旋鈕即可靜音。沒有增益的節點不能作為音量控制目標。

錄音 僅列出錄音機節點。可選擇錄音、暫停或停止。選擇錄音會繼續既有的暫停錄音。錄音資料夾和格式來自 MixRelay 錄音機的選項，在屬性檢查器中為唯讀。
