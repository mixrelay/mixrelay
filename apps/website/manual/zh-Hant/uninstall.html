MIXRELAY / 手冊

解除安裝

使用解除安裝程式或 Linux 套件管理員移除完整產品。

發佈前草稿。目前尚未提供公開下載或購買。本手冊說明目前原始碼建置版本的行為；在下文所列環境中，仍須驗證安裝後的實際行為。

本頁內容

  • 移除前的準備
  • 在 macOS 上移除
  • 在 Linux 上移除

01

移除前的準備

請將需要保留的工作儲存為 .mix 檔案。停止錄音，結束通話和錄音應用程式。如需解除此電腦的付費啟用狀態，請在移除前連線使用取消此裝置的授權。解除安裝本身無法確認伺服器端已停用。

02

在 macOS 上移除

  1. 開啟 /Applications/MixRelay/Uninstall MixRelay.app。
  2. 如需保留虛擬裝置設定，請不要勾選 刪除已儲存的 MixRelay 設定。
  3. 選擇 移除 MixRelay，並核准 macOS 管理者授權要求。目前移除對話框雖然使用這些 Driver 標籤，但會移除完整產品。
  4. 等待確認完成。移除會停止裝置和迴送，並短暫中斷系統音訊。

選用的刪除項目只會移除已儲存的裝置設定。在 macOS 上，音訊圖、錄音、已匯出的工作和付費驗證均會保留。僅將編輯器應用程式移至垃圾桶不會移除已安裝的音訊元件。如果移除失敗，請閱讀訊息並檢查目前安裝狀態後再重試；某些元件可能已被移除。取消授權不會變更產品。

03

在 Linux 上移除

結束編輯器，並在背景狀態選單中選擇 結束。以一般使用者身分開啟已安裝的 解除安裝 MixRelay 應用程式項目。如需保留已儲存的音訊圖和設定，請不要勾選對應的刪除選項。移除程式使用目前工作階段的一般 polkit 驗證代理程式和套件管理員。成功移除後，會清除本機付費授權登入資訊；錄音和已匯出的專案仍會保留。

也可以直接移除 mix-relay 套件。僅選擇適用於您發行版的指令。直接透過套件管理員移除會保留各使用者的設定和本機驗證資訊。

sudo apt remove mix-relay
sudo dnf remove mix-relay
sudo pacman -R mix-relay

如果無法顯示授權介面，請檢查桌面工作階段是否有 polkit 驗證代理程式。如果應用程式已移除但清理失敗，請依顯示的復原訊息操作。請勿刪除無關的音訊服務或使用者資料夾。
