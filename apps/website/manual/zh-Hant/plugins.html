MIXRELAY / 手冊

外掛程式

使用廠商的安裝程式安裝效果器，再於 MixRelay 中掃描偵測。

發佈前草稿。目前尚未提供公開下載或購買。本手冊說明目前原始碼建置版本的行為；在下文所列環境中，仍須驗證安裝後的實際行為。

本頁內容

  • 各平台支援的格式
  • 尋找與使用效果器
  • 掃描、編輯器與格式錯誤

01

各平台支援的格式

  • macOS：VST3、CLAP、AU 和 AUv3。
  • Linux：VST3、CLAP 和 LV2。

清單包含通過偵測與配置檢查的音訊效果器，不提供樂器和 MIDI 工作流程。支援某種格式不代表每個外掛程式、架構或聲道配置都能正常運作。免費版允許兩個外掛程式實例，包括已關閉的實例。偵測到的效果器數量不受限制。

02

尋找與使用效果器

  1. 依照廠商說明，安裝適用於您平台和架構的外掛程式。
  2. 在 新增節點 → 處理器 中選擇 重新掃描音訊效果器。如需使用自訂 VST3、CLAP 或 LV2 位置，請選擇 新增外掛程式資料夾…。
  3. 直接在處理器選單中選擇偵測到的效果器。其說明會標示格式和廠商。檢查 聲道配置，並連接所需的主輸入/輸出、側鏈或輔助連接埠。
  4. 使用節點的 選項 調整公開參數。新增外掛程式節點時，如有可用的原生編輯器，會自動開啟一次。之後可用 開啟 重新開啟。

Linux 原生編輯器需要 X11 或 XWayland。缺少編輯器時不會建立通用原生視窗。如有公開參數，請使用這些參數。

03

掃描、編輯器與格式錯誤

如果出現 效果器搜尋尚未完成，請開啟 掃描問題（…） 和 技術資訊。某個掃描階段失敗時，先前可用的效果器仍會保留在清單中。修正安裝或資料夾後，使用 重試 或重新掃描。

外掛程式當機時，如有 重試已崩潰的外掛程式：…，請使用該操作。如果編輯器無法使用，請查看具體原因，例如沒有原生編輯器或缺少 X11/XWayland。部分 AU/VST/LV2 工作階段因尚未實作原生預設狀態轉移，會拒絕運作中變更格式。目前工作階段會保留，請勿以為要求的格式已經套用。
