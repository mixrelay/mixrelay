MIXRELAY / 手冊

首次啟動與權限

開啟 MixRelay，等待音訊引擎就緒，再選擇要使用的音源。

發佈前草稿。目前尚未提供公開下載或購買。本手冊說明目前原始碼建置版本的行為；在下文所列環境中，仍須驗證安裝後的實際行為。

本頁內容

  • 連線至音訊引擎
  • macOS 音訊擷取與麥克風權限
  • 建立第一條音訊路由

01

連線至音訊引擎

準備音訊時會顯示 正在連線至 MixRelay。如果顯示 需要 MixRelay，請安裝完整產品。如果顯示 請更新 MixRelay，請更新已安裝的產品。如果顯示 無法連線至 MixRelay，請檢查安裝情況後選擇 重新連線。

免費版無須購買或啟用。應用程式會依作業系統的偏好語言順序，使用第一個支援的語言；若無符合項目，則使用英語。外觀 提供 跟隨系統、淺色 和 深色 選項。

02

macOS 音訊擷取與麥克風權限

首次使用應用程式音源時，macOS 可能要求擷取應用程式或系統音訊的權限。使用麥克風或其他實體音訊輸入時，macOS 可能要求麥克風存取權限。如需使用該音源，請允許相應的存取。這是兩項獨立權限；僅允許麥克風存取不會啟用應用程式音訊擷取。

如果先前拒絕了存取，請開啟「系統設定」→「隱私權與安全性」。在「螢幕與系統音訊錄製」下檢查音訊擷取設定，並在「麥克風」中檢查實體輸入權限。標籤和提示會隨 macOS 版本而異。請為發出要求的 MixRelay 項目啟用存取，並依 macOS 的指示重新啟動。接著在 MixRelay 中重試該音源。請參閱 Apple 的螢幕與系統音訊權限指南。

在 Linux 上，音源使用一般的 PipeWire 工作階段，此流程不包含 macOS 式的權限提示。

03

建立第一條音訊路由

  1. 選擇現有音訊圖；如果沒有，選擇 新增音訊圖，輸入 音訊圖名稱，然後選擇 建立。免費版允許使用一個音訊圖。
  2. 透過 新增節點 → 音源 選擇執行中的應用程式或音訊輸入。
  3. 透過 新增節點 → 輸出 選擇音訊輸出。將音源的各個輸出聲道連接至輸出節點的輸入聲道。
  4. 在來源應用程式中播放音訊，或對著輸入裝置說話。檢查電平表和輸出裝置。

如需將混音傳送至 OBS 或 DAW，請將 MixRelay IO 用作虛擬輸出，並在接收應用程式中將其選為輸入。
