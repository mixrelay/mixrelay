MIXRELAY / 手冊

疑難排解與診斷

變更或刪除已儲存的工作前，請先檢查目前訊息和訊號路徑。

發佈前草稿。目前尚未提供公開下載或購買。本手冊說明目前原始碼建置版本的行為；在下文所列環境中，仍須驗證安裝後的實際行為。

本頁內容

  • 無聲、聲音重疊或斷音
  • 變更未套用或未儲存
  • 儲存診斷報告

01

無聲、聲音重疊或斷音

  1. 檢查全域 暫停、節點電源、靜音和已連接的聲道編號。選取的音訊圖不代表其開啟或關閉狀態。
  2. 確認音源正在產生音訊。視需要檢查擷取或麥克風權限及重新選擇應用程式。
  3. 檢查實體輸出及其硬體音量。對於 OBS 或 DAW，請在該應用程式中將 MixRelay IO 選為輸入，並在 MixRelay 中連接 音訊圖 → 裝置。
  4. 聲音重疊時，請檢查直接播放和監聽路由。出現斷音時，如果介面卡支援變更，可嘗試增大 處理緩衝區。

裝置無法使用時，請重新連接，並視需要重新選擇。如果已儲存的格式遭拒，或裝置回復設定失敗，請依照訊息提示重新套用支援的格式。引擎連線和音訊處理是不同狀態：即使引擎可連線，音訊仍可能顯示為停止或失敗。

如果 MixRelay 因引擎反覆故障而暫停，請先檢查最近的變更，再選擇 繼續。不支援以 Docker 為基礎的音訊；請使用一般 Linux 使用者工作階段，並安裝所需版本的 PipeWire 和 WirePlumber。

02

變更未套用或未儲存

尚未套用 並不表示音訊正在運作。如果應用程式提示已保留編輯內容，請檢查目前引擎狀態，準備好後使用 重試。請勿快速重複執行結果不確定的指令。如果持續衝突時提供 用這些編輯內容覆蓋引擎中的音訊圖 或 放棄編輯並重新載入引擎中的音訊圖，請選擇套用目前草稿或將其放棄。

音訊運作時也可能出現儲存警告。如有可能，請在關閉前儲存一份工作區副本。如只需復原配置，儲存目前配置 可重試儲存目前配置；載入已儲存的配置 會用已儲存的配置取代目前配置。效果器錯誤請參閱外掛程式復原指南。授權錯誤請檢查連線和裝置時鐘；啟用結果不確定時需要聯絡支援。

03

儲存診斷報告

  1. 開啟 MixRelay 背景狀態選單。
  2. 選擇 儲存診斷報告…。
  3. 選擇 dump.json 的儲存位置。請先檢查內容，如支援人員要求，再附在支援郵件中。儲存不會上傳檔案。

報告在規定上限內包含版本、作業系統、架構、裝置格式、執行階段狀態和數值計數器資訊，不包含音訊、記憶體傾印、原始記錄、驗證資訊、使用者路徑、裝置名稱與 ID、音訊圖或應用程式清單。報告最多為 256 KiB，包含最多 64 份裝置摘要。無法取得的觀測值會標為無法使用。匯出不會啟動已停止的音訊。

一次只能進行一項匯出。取消不會建立檔案。取代現有檔案需要作業系統的覆寫確認。如果儲存失敗，請檢查目標位置後重試。其他需要提供的資訊請參閱聯絡支援。
