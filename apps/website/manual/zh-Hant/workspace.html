MIXRELAY / 手冊

路由工作區

使用音源、處理器和輸出節點建立音訊圖。連線在各個聲道之間傳送音訊。

發佈前草稿。目前尚未提供公開下載或購買。本手冊說明目前原始碼建置版本的行為；在下文所列環境中，仍須驗證安裝後的實際行為。

本頁內容

  • 音訊圖、節點與儲存

01

音訊圖、節點與儲存

使用 新增音訊圖 建立音訊圖，透過 新增節點 加入 音源、處理器 或 輸出。在 音訊圖 中選擇要編輯的音訊圖。選擇一個音訊圖不會關閉其他音訊圖。有授權時，多個音訊圖可以同時運作。

開啟節點的 選項 可查看可用參數。按兩下節點名稱、在節點取得焦點時按 F2，或使用選單中的 變更顯示名稱 可修改顯示名稱。顯示名稱僅影響目前節點，清空即可恢復原名。

編輯內容和配置會自動儲存。出現儲存警告時，變更可能在重新啟動後遺失。如需可攜式工作區，請使用 檔案 → 儲存 或 另存新檔… 寫入 .mix 檔案。新增工作區 和 開啟… 會在取代目前內容前詢問確認。工作區檔案不會安裝缺少的裝置或外掛程式。

02

連接與對應聲道

將輸出連接埠拖曳至輸入連接埠。立體聲需要連接兩個聲道。按住 Shift 可在同一節點上選取更多輸出聲道，再將所選聲道拖曳至目標的第一個聲道；目標聲道之間的相對位移會保留。按 Escape 可取消並清除聲道選取。

在連線上按右鍵可選擇 刪除連線。連接埠選單提供 斷開聲道 或 斷開所選聲道。選取節點或連線後，按 Delete 或 Backspace 也可刪除。縮放以顯示完整音訊圖 可將整個音訊圖顯示在檢視中。在 macOS 上使用 Command+Z、在 Linux 上使用 Ctrl+Z 復原音訊圖編輯；同時按住 Shift 可重做。

刪除音訊圖 會停止該音訊圖的音訊與錄音。刪除音訊圖無法復原，已儲存的工作區檔案仍會保留。

03

不用拖曳也能連接

  1. 按 Tab 將焦點移至音源節點。按 Enter 或 Space 選取節點。方向鍵可移動選取的節點，按住 Shift 可增加移動幅度。
  2. 按 Shift+F10 或快顯選單鍵，然後選擇 連接聲道…。
  3. 選擇 起始輸出聲道 和 聲道數，或保留既有的聲道選取。再選擇 目標 和 起始輸入聲道。
  4. 查看 預覽，包括略過的連線及其原因。選擇 連接，或選擇 取消 以維持音訊圖不變。

焦點位於連線或畫布時，同樣可以使用這些快顯選單快捷鍵。節點內的控制項保留各自的鍵盤操作方式。按 Escape 可關閉選單和對話框。

04

關閉、靜音、旁通、暫停與結束

  • 關閉節點電源會停用處理，並阻斷其訊號。
  • 靜音會繼續處理，但使節點輸出無聲。
  • 效果器的 旁通 會保留設定並傳遞乾音。
  • 頁尾或狀態選單中的 暫停 會暫停所有音訊圖和進行中的錄音。繼續 從當前音訊繼續；暫停期間的音訊會捨棄。虛擬裝置的 ID、名稱和格式保持不變。

關閉編輯器後，路由、效果、擷取和錄音仍會在背景運作。在 macOS 上，關閉視窗會將其隱藏，結束編輯器則會結束編輯器程序。在 Linux 上，關閉視窗會結束編輯器程序。使用狀態選單中的 開啟 MixRelay 可返回編輯器。

背景狀態選單中的 結束 會停止裝置和迴送，並完成錄音檔案的收尾。重新開啟 MixRelay 會還原已儲存的裝置。已儲存的全域暫停狀態會保持到您繼續音訊為止；手動暫停或已停止的錄音機不會只因您繼續所有音訊而開始錄音。
