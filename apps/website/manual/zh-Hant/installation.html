MIXRELAY / 手冊

系統需求與安裝

安裝適用於您作業系統的完整 MixRelay 產品，無須另外安裝 Driver。

發佈前草稿。目前尚未提供公開下載或購買。本手冊說明目前原始碼建置版本的行為；在下文所列環境中，仍須驗證安裝後的實際行為。

本頁內容

  • 支援的環境
  • 在 macOS 上安裝
  • Gatekeeper 檢查
  • 在 Linux 上安裝

01

支援的環境

  • macOS 14.2 或以上版本，Apple Silicon 或 Intel。安裝程式為 Universal 2。透過已安裝建置版本檢查的最新主要版本為 macOS 27。
  • Linux x86_64 或 arm64，在已登入的使用者工作階段中使用 PipeWire 1.2 或以上版本及 WirePlumber 0.5 或以上版本。目前套件需要 glibc 2.39。

Linux 建置與程式碼測試涵蓋兩種架構的 Debian 13、Ubuntu 26.04 和 Kali rolling，以及 x86_64 的 Arch。這不代表已驗證所有發行版的安裝。未經更動的 Ubuntu 24.04 音訊套件版本過舊。支援一般 Linux 虛擬機器，不支援 Docker 音訊環境。不支援 Windows。

macOS 檢查未涵蓋所有支援的系統版本：已檢查 14.8.7 虛擬機器的安裝、服務及虛擬裝置，但未檢查其權限對話框和即時擷取。14.2–14.7、15 和 26 的安裝檢查仍未完成。

02

在 macOS 上安裝

  1. 開放公開下載後，取得官方的 MixRelay-Installer-VERSION.pkg。
  2. 結束錄音和通話應用程式。安裝會短暫中斷系統音訊。
  3. 開啟 PKG。閱讀 App 和 Driver 元件協議，然後依安裝程式中的「繼續」和「同意」步驟操作。出現提示時，使用 macOS 管理者帳號授權安裝。
  4. 安裝完成後，開啟 /Applications/MixRelay/MixRelay.app。無須重新啟動。

此套件會一併安裝編輯器、背景音訊元件、虛擬裝置及 Uninstall MixRelay.app，不提供元件選擇。現有裝置、音訊圖、設定、錄音和驗證資訊都會保留。

03

Gatekeeper 檢查

公開發佈的 macOS 套件必須經過 Developer ID 簽署和公證。macOS 可能要求您確認是否開啟下載的軟體。如果 macOS 提示開發者身分不明、無法驗證套件、檔案已損壞或含有惡意軟體，請停止操作，重新取得官方套件或聯絡支援。請勿為了安裝而停用 Gatekeeper 或移除隔離屬性。請參閱 Apple 關於開啟已下載 App 的說明。

04

在 Linux 上安裝

請使用發行版的套件管理員，以便解決相依性。將範例檔名替換為您下載的、適用於相應架構的套件檔名。

sudo apt install ./MixRelay_VERSION_ARCH.deb
sudo dnf install ./MixRelay-VERSION-1.ARCH.rpm
sudo pacman -U ./mix-relay-VERSION-1-x86_64.pkg.tar.zst

僅執行適用於您發行版的指令。套件名稱為 mix-relay。請以一般使用者身分從應用程式選單啟動 MixRelay。PipeWire 音訊在該使用者的工作階段中執行，切勿以 root 身分執行。無須 SDK 或手動設定服務。AppImage 並非支援的安裝或更新方式。
