MIXRELAY / MANUAL

Requisitos del sistema e instalación

Instala el producto MixRelay completo para tu sistema operativo. No se necesita instalar Driver por separado.

Borrador previo al lanzamiento. Las descargas y las compras públicas aún no están disponibles. Estas instrucciones describen la compilación actual del código fuente; aún queda por verificar el comportamiento de la instalación en los entornos indicados a continuación.

01

Entornos compatibles

  • macOS 14.2 o posterior, Apple Silicon o Intel. El instalador es Universal 2. macOS 27 es la versión principal más reciente que se ha comprobado con una compilación instalada.
  • Linux x86_64 o arm64, en una sesión de usuario iniciada, con PipeWire 1.2 o posterior y WirePlumber 0.5 o posterior. Los paquetes actuales requieren glibc 2.39.

Las pruebas de compilación y código en Linux abarcan Debian 13, Ubuntu 26.04 y Kali rolling en ambas arquitecturas, y Arch en x86_64. Esto no confirma la instalación en todas las distribuciones. Los paquetes de audio originales de Ubuntu 24.04 son demasiado antiguos. Se admiten máquinas virtuales Linux normales; no se admiten entornos de audio en Docker. Windows no es compatible.

Las comprobaciones de macOS no abarcan todas las versiones compatibles del sistema: se verificaron la instalación, los servicios y los dispositivos virtuales en una VM con 14.8.7, pero no sus diálogos de permisos ni la captura en directo. Las comprobaciones de instalación para 14.2–14.7, 15 y 26 siguen incompletas.

02

Instalar en macOS

  1. Cuando las descargas públicas estén disponibles, obtén el paquete oficial MixRelay-Installer-VERSION.pkg.
  2. Cierra las aplicaciones de grabación y llamadas. La instalación interrumpe brevemente el audio del sistema.
  3. Abre el PKG. Lee los acuerdos de los componentes App y Driver y sigue los pasos Continuar y Aceptar del Instalador. Cuando se solicite, autoriza la instalación con una cuenta de administrador de macOS.
  4. Tras la instalación, abre /Applications/MixRelay.app. No es necesario reiniciar.

El paquete instala juntos el editor, el audio en segundo plano, los dispositivos virtuales y Uninstall MixRelay.app. No hay selección de componentes. Se conservan los dispositivos, grafos, ajustes, grabaciones y datos de autenticación existentes.

03

Comprobaciones de Gatekeeper

Los paquetes públicos de macOS deben estar firmados con Developer ID y notarizados. macOS puede pedirte que confirmes la apertura del software descargado. Si macOS informa de un desarrollador no identificado, un paquete que no puede verificar, daños o software malicioso, detente y obtén un nuevo paquete oficial o contacta con soporte. No desactives Gatekeeper ni elimines los atributos de cuarentena para instalar. Consulta la guía de Apple para abrir aplicaciones descargadas.

04

Instalar en Linux

Usa el gestor de paquetes de tu distribución para que resuelva las dependencias. Sustituye el nombre de archivo del ejemplo por el paquete descargado para tu arquitectura.

sudo apt install ./MixRelay_VERSION_ARCH.deb
sudo dnf install ./MixRelay-VERSION-1.ARCH.rpm
sudo pacman -U ./mix-relay-VERSION-1-x86_64.pkg.tar.zst

Ejecuta solo el comando de tu distribución. El paquete se llama mix-relay. Inicia MixRelay desde el menú de aplicaciones con tu usuario habitual. El audio de PipeWire se ejecuta en la sesión de ese usuario, nunca como root. No necesitas un SDK ni configurar servicios manualmente. AppImage no es una vía de instalación ni actualización admitida.
