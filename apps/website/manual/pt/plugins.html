MIXRELAY / MANUAL

Plug-ins externos

Instale os efeitos com o instalador do fabricante e depois busque-os no MixRelay.

Rascunho de pré-lançamento. Os downloads e as compras públicas ainda não estão disponíveis. Estas instruções descrevem a compilação atual do código-fonte; o comportamento após a instalação ainda precisa ser verificado nos ambientes indicados abaixo.

Nesta página

  • Formatos por plataforma

01

Formatos por plataforma

  • macOS: VST3, CLAP, AU e AUv3.
  • Linux: VST3, CLAP e LV2.

A lista contém efeitos de áudio que passam pelas verificações de detecção e configuração de canais. Não há fluxos de trabalho com instrumentos ou MIDI. Um formato compatível não garante que todos os plug-ins, arquiteturas ou configurações de canais funcionem. A versão gratuita permite duas instâncias de plug-ins externos, incluindo as desligadas. Não há limite de efeitos encontrados.

02

Buscar e usar um efeito

  1. Instale o plug-in para sua plataforma e arquitetura seguindo as instruções do fabricante.
  2. Em Adicionar nó → Processador, escolha Buscar efeitos de áudio novamente. Para um local personalizado de VST3, CLAP ou LV2, escolha Adicionar pasta de plug-ins….
  3. Selecione um efeito encontrado diretamente no menu Processador. A descrição informa o formato e o fabricante. Confira Configuração de canais e conecte as portas principais, de cadeia lateral ou auxiliares necessárias.
  4. Use Opções do nó para os parâmetros expostos. Um nó de plug-in novo abre uma vez o editor nativo, quando disponível. Use Abrir para reabri-lo.

Os editores nativos no Linux exigem X11 ou XWayland. A ausência de um editor não cria uma janela nativa genérica. Use os parâmetros expostos quando disponíveis.

03

Erros de busca, editor e formato

Se aparecer Busca de efeitos incompleta, abra Problemas na busca e Detalhes técnicos. Os efeitos disponíveis anteriormente continuam na lista quando uma etapa da busca falha. Corrija a instalação ou a pasta e use Tentar novamente ou faça uma nova busca.

Se um plug-in falhar, use Tentar novamente o plug-in que falhou: … quando essa opção aparecer. Se um editor estiver indisponível, leia o motivo específico, como a ausência de editor nativo ou de X11/XWayland. Algumas sessões com AU/VST/LV2 rejeitam mudanças de formato durante o funcionamento porque a transferência do estado de predefinições nativas não foi implementada. A sessão atual é mantida; não presuma que o formato solicitado foi aplicado.
