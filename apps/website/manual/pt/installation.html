MIXRELAY / MANUAL

Requisitos do sistema e instalação

Instale o produto MixRelay completo para seu sistema operacional. Não é necessário instalar o Driver separadamente.

Rascunho de pré-lançamento. Os downloads e as compras públicas ainda não estão disponíveis. Estas instruções descrevem a compilação atual do código-fonte; o comportamento após a instalação ainda precisa ser verificado nos ambientes indicados abaixo.

01

Ambientes compatíveis

  • macOS 14.2 ou posterior, Apple Silicon ou Intel. O instalador é Universal 2. O macOS 27 é a versão principal mais recente verificada com uma compilação instalada.
  • Linux x86_64 ou arm64, em uma sessão de usuário iniciada, com PipeWire 1.2 ou posterior e WirePlumber 0.5 ou posterior. Os pacotes atuais exigem glibc 2.39.

Os testes de compilação e código no Linux abrangem Debian 13, Ubuntu 26.04 e Kali rolling nas duas arquiteturas, e Arch em x86_64. Isso não confirma a instalação em todas as distribuições. Os pacotes de áudio originais do Ubuntu 24.04 são antigos demais. Máquinas virtuais Linux comuns são compatíveis; ambientes de áudio em Docker não são compatíveis. Não há suporte ao Windows.

As verificações do macOS não abrangem todas as versões compatíveis do sistema: foram verificados a instalação, os serviços e os dispositivos virtuais em uma VM com 14.8.7, mas não os diálogos de permissão nem a captura ao vivo. As verificações de instalação para 14.2–14.7, 15 e 26 continuam incompletas.

02

Instalar no macOS

  1. Quando os downloads públicos estiverem disponíveis, obtenha o pacote oficial MixRelay-Installer-VERSION.pkg.
  2. Feche os aplicativos de gravação e chamadas. A instalação interrompe brevemente o áudio do sistema.
  3. Abra o PKG. Leia os contratos dos componentes App e Driver e siga as etapas Continuar e Concordar do Instalador. Quando solicitado, autorize a instalação com uma conta de administrador do macOS.
  4. Após a instalação, abra /Applications/MixRelay.app. Não é necessário reiniciar.

O pacote instala juntos o editor, o áudio em segundo plano, os dispositivos virtuais e Uninstall MixRelay.app. Não há seleção de componentes. Os dispositivos, grafos, configurações, gravações e dados de autenticação existentes são mantidos.

03

Verificações do Gatekeeper

Os pacotes públicos do macOS devem ser assinados com Developer ID e notarizados. O macOS pode pedir a confirmação de abertura do software baixado. Se informar um desenvolvedor não identificado, um pacote que não pode verificar, danos ou malware, interrompa o processo e obtenha um novo pacote oficial ou entre em contato com o suporte. Não desative o Gatekeeper nem remova atributos de quarentena como etapa de instalação. Consulte as orientações da Apple para abrir aplicativos baixados.

04

Instalar no Linux

Use o gerenciador de pacotes da sua distribuição para resolver as dependências. Substitua o nome de arquivo do exemplo pelo pacote baixado para sua arquitetura.

sudo apt install ./MixRelay_VERSION_ARCH.deb
sudo dnf install ./MixRelay-VERSION-1.ARCH.rpm
sudo pacman -U ./mix-relay-VERSION-1-x86_64.pkg.tar.zst

Execute apenas o comando da sua distribuição. O nome do pacote é mix-relay. Inicie o MixRelay pelo menu de aplicativos com seu usuário normal. O áudio do PipeWire roda na sessão desse usuário, nunca como root. Você não precisa de um SDK nem de configuração manual de serviços. AppImage não é uma forma de instalação ou atualização compatível.
