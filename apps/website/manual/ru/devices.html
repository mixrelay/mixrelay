MIXRELAY / РУКОВОДСТВО

Устройства и виртуальные подключения

Используйте MixRelay IO для обмена аудио с другими приложениями. Формат устройства не зависит от формата записи.

Предрелизный черновик. Публичные загрузки и покупки пока недоступны. Эти инструкции описывают текущую сборку из исходного кода; поведение установленного продукта ещё предстоит проверить в указанных ниже средах.

01

Выбор направления аудио

MixRelay IO — виртуальное устройство по умолчанию. Чтобы получать звук, который другое приложение воспроизводит через него, добавьте его через Добавить узел → Источник → MixRelay Virtual I/O. Это направление Устройство → граф. Чтобы отправить микс графа в приложение, например OBS, добавьте устройство через Добавить узел → Выход → MixRelay Virtual I/O. Это направление Граф → устройство. В OBS или вашей DAW выберите MixRelay IO в качестве аудиовхода.

Подключите нужные каналы. MixRelay не выбирает системное устройство по умолчанию и не добавляет маршрут аппаратного мониторинга за вас. Для мониторинга добавьте физический выход и подключите к нему микс. Driver также обеспечивает базовый loopback от воспроизведения ОС к захвату без ограничений редактора на маршруты каналов графа.

Удаление ссылки на устройство из графа не удаляет само виртуальное устройство. С лицензией можно создавать устройства через Новое виртуальное устройство. При удалении устройства через меню состояния удаляются и его сохранённые настройки; другие приложения, использующие его, теряют это устройство.

02

Каналы, частоты дискретизации и PCM

Откройте Параметры виртуального узла, чтобы изменить Имя устройства, Каналы, частоту дискретизации и Разрядность. Доступны только поддерживаемые общие настройки. Для переименования нужна лицензия. В меню состояния можно выбрать 2, 4, 8, 16, 32 или 64 канала; само устройство поддерживает 1–64 канала в каждом направлении.

В macOS поддерживаются частоты 44.1, 48, 88.2, 96, 176.4 и 192 kHz. Форматы устройства: Float32, PCM16, упакованный PCM24 и PCM32. В Linux доступны сочетания, поддерживаемые PipeWire. Возможности физических устройств зависят от самих устройств. Внутренняя обработка DSP использует Float32; изменение разрядности устройства не меняет формат записи WAV.

Изменение формата ненадолго прерывает звук. При ошибке проверьте сообщение и текущее значение перед повторной попыткой. Ошибка сохранения может означать, что устройство изменилось, но его новые настройки не сохранились.

03

Буферы обработки и задержка

Параметр Буфер обработки на нижней панели меняет буфер ввода/вывода движка, если поддерживаются изменения во время работы. Выбранное значение применяется сразу. При устранимой ошибке кнопка Применить повторяет попытку применить поддерживаемую настройку. Меньший буфер может уменьшить задержку буфера, но повысить вероятность прерываний. Увеличьте его, если звук прерывается.

Отдельного выбора буфера для каждого виртуального устройства нет. Другие приложения выбирают собственные клиентские буферы. Задержка буфера — длительность одного буфера обработки, а не полная задержка ввода/вывода. Она не гарантирует единый квант обработки для всего PipeWire. При использовании нескольких физических устройств могут потребоваться преобразование частоты дискретизации и синхронизация часов.

Для захвата приложений сейчас требуется 48 kHz. На нижней панели есть управление буфером, но нет выбора частоты дискретизации обработки. Частоты виртуальных устройств меняются в настройках устройств. Некоторые нативные плагины не позволяют менять формат во время работы, поскольку перенос состояния их пресетов пока не реализован.
