MIXRELAY / РУКОВОДСТВО

Системные требования и установка

Установите MixRelay целиком для своей операционной системы. Отдельная установка Driver не нужна.

Предрелизный черновик. Публичные загрузки и покупки пока недоступны. Эти инструкции описывают текущую сборку из исходного кода; поведение установленного продукта ещё предстоит проверить в указанных ниже средах.

01

Поддерживаемые среды

  • macOS 14.2 или новее, Apple Silicon или Intel. Установщик — Universal 2. macOS 27 — последняя основная версия, проверенная с установленной сборкой.
  • Linux x86_64 или arm64, в сеансе вошедшего в систему пользователя, с PipeWire 1.2 или новее и WirePlumber 0.5 или новее. Текущие пакеты требуют glibc 2.39.

Проверки сборки и кода в Linux охватывают Debian 13, Ubuntu 26.04 и Kali rolling на обеих архитектурах, а также Arch на x86_64. Это не подтверждает установку на всех дистрибутивах. Исходные аудиопакеты Ubuntu 24.04 слишком старые. Обычные виртуальные машины Linux поддерживаются; аудиосреды Docker не поддерживаются. Windows не поддерживается.

Проверки macOS охватывают не все поддерживаемые версии ОС: в VM с 14.8.7 проверены установка, службы и виртуальные устройства, но не диалоги разрешений и захват в реальном времени. Проверки установки для 14.2–14.7, 15 и 26 ещё не завершены.

02

Установка в macOS

  1. Когда появятся публичные загрузки, скачайте официальный пакет MixRelay-Installer-VERSION.pkg.
  2. Закройте приложения для записи и звонков. Установка ненадолго прерывает системный звук.
  3. Откройте PKG. Прочитайте соглашения для компонентов App и Driver, затем выполните шаги Продолжить и Принимаю в Установщике. При запросе разрешите установку с помощью учётной записи администратора macOS.
  4. После установки откройте /Applications/MixRelay.app. Перезапуск не требуется.

Пакет устанавливает редактор, фоновое аудио, виртуальные устройства и Uninstall MixRelay.app вместе. Выбора компонентов нет. Существующие устройства, графы, настройки, записи и данные аутентификации сохраняются.

03

Проверки Gatekeeper

Публичные пакеты macOS должны быть подписаны Developer ID и нотариально заверены Apple. macOS может запросить подтверждение открытия загруженной программы. Если macOS сообщает о неизвестном разработчике, невозможности проверить пакет, повреждении или вредоносном ПО, остановитесь и скачайте новый официальный пакет либо обратитесь в поддержку. Не отключайте Gatekeeper и не удаляйте атрибуты карантина ради установки. См. рекомендации Apple по открытию загруженных приложений.

04

Установка в Linux

Используйте менеджер пакетов своего дистрибутива, чтобы он разрешил зависимости. Замените имя файла из примера на имя загруженного пакета для своей архитектуры.

sudo apt install ./MixRelay_VERSION_ARCH.deb
sudo dnf install ./MixRelay-VERSION-1.ARCH.rpm
sudo pacman -U ./mix-relay-VERSION-1-x86_64.pkg.tar.zst

Выполните только команду для своего дистрибутива. Пакет называется mix-relay. Запустите MixRelay из меню приложений от обычного пользователя. Аудио PipeWire работает в сеансе этого пользователя, никогда от root. SDK и ручная настройка служб не нужны. AppImage не является поддерживаемым способом установки или обновления.
