MIXRELAY / マニュアル

システム要件とインストール

お使いのOSにMixRelay製品一式をインストールします。Driverを別途インストールする必要はありません。

公開前の草稿です。一般向けのダウンロードと購入はまだ利用できません。本書は現在のソースからビルドした製品を説明しています。以下に記載する環境では、インストール後の動作確認が引き続き必要です。

01

対応環境

  • macOS 15.0以降、Apple SiliconまたはIntel。インストーラーはUniversal 2です。インストール済みのビルドで確認した最新のメジャーバージョンはmacOS 27です。
  • Linux x86_64またはarm64。ログイン済みのユーザーセッションで、PipeWire 1.2以降とWirePlumber 0.5以降が必要です。現在のパッケージにはglibc 2.39が必要です。

Linuxのビルドとコードのテストは、両アーキテクチャのDebian 13、Ubuntu 26.04、Kali rolling、およびx86_64のArchを対象としています。すべてのディストリビューションへのインストールを確認したものではありません。標準のUbuntu 24.04の音声パッケージは古すぎます。通常のLinux仮想マシンには対応していますが、Dockerの音声環境とWindowsには対応していません。

Intel搭載Macは、macOS 15〜26を実行するApple対応モデルでサポートします。各リリースは、Apple SiliconとIntelのmacOS 15・26、Apple SiliconのmacOS 27にインストールして確認します。すべてのパッチバージョンを確認しているわけではありません。

02

macOSにインストールする

  1. 一般向けのダウンロードが公開されたら、公式のMixRelay-Installer-VERSION.pkgを入手します。
  2. 録音アプリと通話アプリを終了します。インストール中はシステムの音声が一時的に途切れます。
  3. PKGを開きます。AppとDriverの各コンポーネントの契約を読み、インストーラの「続ける」「同意する」の手順を進めます。求められたら、macOSの管理者アカウントでインストールを承認します。
  4. インストール後、/Applications/MixRelay/MixRelay.appを開きます。再起動は不要です。

このパッケージは、エディター、バックグラウンドの音声処理、仮想デバイス、Uninstall MixRelay.appをまとめてインストールします。コンポーネントの選択はありません。既存のデバイス、グラフ、設定、録音、認証情報は保持されます。

03

Gatekeeperの確認

一般公開するmacOSパッケージにはDeveloper ID署名と公証が必要です。ダウンロードしたソフトウェアを開く際、macOSから確認を求められることがあります。開発元を確認できない、パッケージを検証できない、破損している、マルウェアが含まれると表示された場合は作業を中止し、公式パッケージを再取得するかサポートに連絡してください。インストールのためにGatekeeperを無効にしたり、隔離属性を削除したりしないでください。ダウンロードしたアプリを開く際のAppleの案内を参照してください。

04

Linuxにインストールする

依存関係を解決できるよう、ディストリビューションのパッケージマネージャーを使用します。例のファイル名を、お使いのアーキテクチャ用にダウンロードしたパッケージ名に置き換えてください。

sudo apt install ./MixRelay_VERSION_ARCH.deb
sudo dnf install ./MixRelay-VERSION-1.ARCH.rpm
sudo pacman -U ./mix-relay-VERSION-1-x86_64.pkg.tar.zst

お使いのディストリビューションに対応するコマンドだけを実行してください。パッケージ名はmix-relayです。通常のユーザーとしてアプリケーションメニューからMixRelayを起動します。PipeWireの音声処理はそのユーザーのセッションで動作し、rootでは実行しません。SDKやサービスの手動設定は不要です。AppImageによるインストールと更新には対応していません。
