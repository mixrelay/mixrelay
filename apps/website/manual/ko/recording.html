그래프에 연결한 신호를 RF64 WAV 파일로 녹음하세요.

사전 공개 초안입니다. 공개 다운로드와 구매는 아직 제공하지 않습니다. 현재 소스 빌드를 기준으로 작성했으며 아래에 표시한 환경의 설치본 검증은 남아 있습니다.

이 페이지 목차

  • 설정과 녹음
  • 일시정지와 파일 마무리
  • 무료 한도와 기술적 상한

01

설정과 녹음

  1. 노드 추가 → 출력 → 레코더를 선택하세요. 녹음할 채널을 연결하세요.
  2. 옵션을 여세요. 채널 수를 정하고 폴더 선택…으로 녹음 폴더를 선택하세요.
  3. WAV 샘플레이트와 비트 심도를 선택하세요. 입력과 동일은 녹음을 시작할 때 입력 샘플레이트를 따릅니다. 비트 심도는 PCM16·PCM24·Float32입니다.
  4. 녹음을 누르세요. MixRelay가 파일명을 만듭니다. 필요에 따라 일시정지·재개·정지를 사용하세요.

녹음 설정을 바꾸려면 먼저 정지하세요. 녹음 중이거나 일시정지 중이면 설정이 잠깁니다. 녹음당 RF64 .wav 파일 하나를 만들며 4 GiB가 넘어도 나누지 않습니다. RF64 지원 프로그램으로 여세요. MP3 녹음은 제공하지 않습니다.

02

일시정지와 파일 마무리

재개하면 같은 파일에 이어서 기록합니다. 일시정지 구간은 무음으로 채우지 않습니다. 10초 녹음하고 5초 일시정지한 뒤 10초 더 녹음하면 20초 파일이 됩니다. 녹음 시간은 파일에 쓴 오디오의 시간을 셉니다.

전체 일시정지는 진행 중인 레코더도 일시정지합니다. 전체 재개는 수동으로 일시정지하거나 이미 정지한 레코더를 시작하지 않습니다. 전체 일시정지 중에도 레코더의 정지로 파일을 마무리할 수 있습니다. 정지하면 WAV 헤더를 마무리합니다. 편집 앱을 닫아도 녹음은 계속되며 백그라운드 오디오를 종료하면 열린 녹음 파일을 마무리합니다.

03

무료 한도와 기술적 상한

무료 녹음은 레코더 1개·최대 2채널·녹음당 기록된 오디오 2시간까지입니다. 일시정지 시간은 제외합니다. 한도에 도달하면 파일을 정상 마무리하고 라우팅은 계속합니다. 일시정지한 파일도 레코더 한도에 포함됩니다.

유료 엔진은 레코더당 1–8채널과 최대 16개 녹음 세션을 지원합니다. 시간 한도는 녹음 시작 시 고정합니다. 나중에 활성화해도 무료로 시작한 녹음의 한도는 늘어나지 않으며, 유료로 시작한 녹음은 인증이 만료돼도 잘리지 않습니다. 현재 인증의 한도를 쓰려면 새 녹음을 시작하세요.

녹음 오류가 표시되면 선택한 폴더·쓰기 권한·남은 디스크 공간을 확인하세요. 정지하고 저장한 파일을 확인한 뒤 새 녹음을 시작하세요.
