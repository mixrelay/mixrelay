MIXRELAY / MANUAL

외부 플러그인

제작사의 설치 프로그램으로 효과를 설치한 뒤 MixRelay에서 검색하세요.

사전 공개 초안입니다. 공개 다운로드와 구매는 아직 제공하지 않습니다. 현재 소스 빌드를 기준으로 작성했으며 아래에 표시한 환경의 설치본 검증은 남아 있습니다.

이 페이지 목차

  • 플랫폼별 형식
  • 효과 검색과 사용
  • 검색·편집기·형식 오류

01

플랫폼별 형식

  • macOS: VST3·CLAP·AU·AUv3.
  • Linux: VST3·CLAP·LV2.

검색과 채널 구성 확인을 통과한 오디오 효과를 표시합니다. 악기·MIDI 작업 흐름은 제공하지 않습니다. 형식을 지원해도 모든 플러그인·아키텍처·채널 구성의 동작을 보장하지는 않습니다. 무료 기능에서는 꺼진 인스턴스를 포함해 외부 플러그인 2개를 사용할 수 있습니다. 검색되는 효과 수에는 제한이 없습니다.

02

효과 검색과 사용

  1. 제작사 안내에 따라 플랫폼·아키텍처에 맞는 플러그인을 설치하세요.
  2. 노드 추가 → 프로세서에서 오디오 이펙트 다시 스캔을 선택하세요. 별도 VST3·CLAP·LV2 설치 위치는 플러그인 폴더 추가…로 지정하세요.
  3. 프로세서 메뉴에서 검색된 효과를 직접 선택하세요. 설명에 형식과 제작사가 표시됩니다. 채널 구성을 확인하고 필요한 메인·사이드체인·보조 포트를 연결하세요.
  4. 노드의 옵션에서 제공하는 파라미터를 조절하세요. 새 플러그인 노드는 제공되는 네이티브 편집기를 한 번 엽니다. 다시 열려면 열기를 사용하세요.

Linux 네이티브 편집기에는 X11 또는 XWayland가 필요합니다. 편집기가 없으면 네이티브 창을 임의로 만들지 않습니다. 제공하는 파라미터가 있으면 사용하세요.

03

검색·편집기·형식 오류

이펙트 검색 미완료가 표시되면 검색 오류와 기술 정보를 확인하세요. 검색 단계가 실패해도 이전에 확인한 효과 목록은 유지합니다. 설치나 폴더를 수정한 뒤 다시 시도 또는 재스캔을 사용하세요.

중단된 플러그인에 중단된 플러그인 다시 시도: …가 표시되면 사용할 수 있습니다. 편집기를 열 수 없으면 네이티브 편집기 없음·X11/XWayland 없음 등 표시된 이유를 확인하세요. 일부 AU/VST/LV2 세션은 네이티브 프리셋 상태 이전이 구현되지 않아 실행 중 형식 변경을 거부합니다. 현재 세션은 유지되므로 요청한 형식이 적용됐다고 판단하지 마세요.
