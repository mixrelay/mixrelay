MIXRELAY / MANUAL

제거

제거 앱이나 Linux 패키지 관리자로 제품 전체를 제거하세요.

사전 공개 초안입니다. 공개 다운로드와 구매는 아직 제공하지 않습니다. 현재 소스 빌드를 기준으로 작성했으며 아래에 표시한 환경의 설치본 검증은 남아 있습니다.

이 페이지 목차

  • 제거 전 준비
  • macOS 제거
  • Linux 제거

01

제거 전 준비

필요한 작업을 .mix 파일로 저장하세요. 녹음을 정지하고 통화·녹음 앱을 종료하세요. 이 컴퓨터의 유료 활성화를 해제하려면 온라인에서 먼저 이 기기 비활성화를 사용하세요. 제품 제거가 서버 활성화 해제를 확인해 주지는 않습니다.

02

macOS 제거

  1. /Applications/Uninstall MixRelay.app을 여세요.
  2. 가상 장치 설정을 보존하려면 저장된 MixRelay 설정 삭제를 선택하지 마세요.
  3. MixRelay 제거를 누르고 macOS 관리자 요청을 승인하세요. 현재 제거 창은 이 Driver 문구를 사용하지만 제품 전체를 제거합니다.
  4. 완료 확인을 기다리세요. 장치와 루프백이 중지되며 시스템 오디오가 잠시 끊깁니다.

삭제 옵션은 저장된 장치 설정만 지웁니다. macOS에서는 그래프·녹음·내보낸 작업·유료 인증을 보존합니다. 편집 앱만 휴지통에 넣어도 설치된 오디오 구성요소는 제거되지 않습니다. 실패하면 메시지를 읽고 현재 설치 상태를 확인한 뒤 다시 시도하세요. 일부 구성요소는 이미 제거되었을 수 있습니다. 관리자 인증을 취소하면 제품 상태는 바뀌지 않습니다.

03

Linux 제거

편집 앱을 종료하고 백그라운드 상태 메뉴의 종료를 선택하세요. 일반 사용자로 설치된 MixRelay 제거 앱 항목을 여세요. 그래프와 설정을 보존하려면 저장된 그래프·설정 삭제 옵션을 선택하지 마세요. 제거 앱은 세션의 기본 polkit 인증 에이전트와 패키지 관리자를 사용합니다. 성공하면 로컬 유료 라이선스 로그인 정보를 지우며 녹음·내보낸 프로젝트는 보존합니다.

mix-relay 패키지를 직접 제거할 수도 있습니다. 배포판에 맞는 명령 하나만 선택하세요. 패키지 관리자로 직접 제거하면 사용자별 설정과 로컬 인증을 보존합니다.

sudo apt remove mix-relay
sudo dnf remove mix-relay
sudo pacman -R mix-relay

인증창이 나타나지 않으면 데스크톱 세션에 polkit 인증 에이전트가 있는지 확인하세요. 앱은 제거했지만 정리에 실패했다면 표시된 복구 안내를 따르세요. 다른 오디오 서비스나 사용자 폴더를 지우지 마세요.
