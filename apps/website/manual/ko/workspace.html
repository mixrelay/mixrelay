01

그래프·노드·저장

새 그래프로 그래프를 만들고 노드 추가에서 소스·프로세서·출력을 추가하세요. 그래프 목록에서 편집 대상을 선택합니다. 선택을 바꿔도 다른 그래프는 꺼지지 않습니다. 유료 인증이 있으면 여러 그래프를 함께 실행할 수 있습니다.

노드의 옵션을 열어 제공하는 설정을 조절하세요. 이름을 두 번 클릭하거나 노드에 포커스를 두고 F2를 누르거나 메뉴의 표시 이름 변경을 사용하세요. 표시 이름은 해당 노드에만 적용됩니다. 비우면 원래 이름으로 돌아갑니다.

편집과 배치는 자동 저장됩니다. 저장 경고가 표시되면 재시작 후 변경 사항이 사라질 수 있습니다. 작업 공간을 파일로 보관하려면 파일 → 저장 또는 다른 이름으로 저장…으로 .mix 파일을 만드세요. 새 작업 공간과 열기…는 현재 내용을 교체하기 전에 확인합니다. 작업 공간 파일이 없는 장치나 플러그인을 설치해 주지는 않습니다.

02

채널 연결과 매핑

출력 포트에서 입력 포트로 드래그하세요. 스테레오는 두 채널을 모두 연결합니다. Shift를 누른 채 같은 노드의 출력 채널을 더 선택하고 대상의 첫 채널로 드래그할 수 있습니다. 대상 채널의 간격을 유지해 연결합니다. Escape로 취소하고 채널 선택을 해제하세요.

케이블을 오른쪽 클릭하면 케이블 삭제가 있습니다. 포트 메뉴에는 채널 연결 해제 또는 선택 채널 연결 해제가 있습니다. 노드나 케이블을 선택한 뒤 Delete 또는 Backspace로 삭제할 수 있습니다. 그래프 전체 보기로 그래프를 화면에 맞추세요. macOS의 Command+Z, Linux의 Ctrl+Z로 그래프 편집을 실행 취소하고 Shift를 함께 눌러 다시 실행하세요.

그래프 삭제는 해당 그래프의 오디오와 녹음을 멈춥니다. 그래프 삭제는 되돌릴 수 없으며 저장한 작업 공간 파일은 남습니다.

03

드래그 없이 연결하기

  1. Tab으로 출발 노드에 포커스를 두세요. Enter 또는 Space로 선택합니다. 방향키로 선택한 노드를 옮기고 Shift를 함께 누르면 더 크게 옮깁니다.
  2. Shift+F10 또는 메뉴 키를 누르고 채널 연결…을 선택하세요.
  3. 첫 출력 채널과 채널 수를 지정하거나 기존 채널 선택을 유지하세요. 대상과 첫 입력 채널을 선택하세요.
  4. 미리 보기에서 연결과 건너뛰는 이유를 확인하세요. 연결을 누르거나 취소로 변경 없이 닫으세요.

케이블이나 캔버스에 포커스를 두고 같은 키로 메뉴를 열 수 있습니다. 노드 안의 조작은 고유한 키 동작을 유지합니다. Escape로 메뉴와 대화상자를 닫으세요.

04

끄기·음소거·바이패스·일시정지·종료

  • 노드의 전원을 끄면 처리가 제외되고 신호가 차단됩니다.
  • 음소거는 처리를 유지하면서 노드 출력을 끕니다.
  • 효과의 바이패스는 설정을 유지하면서 원음을 통과시킵니다.
  • 하단 또는 상태 메뉴의 일시정지는 모든 그래프와 진행 중인 녹음을 일시정지합니다. 재개하면 현재 소리를 처리합니다. 일시정지 중 소리는 버리며 가상 장치의 ID·이름·형식은 유지합니다.

편집 앱을 닫아도 라우팅·효과·캡처·녹음은 백그라운드에서 계속됩니다. macOS에서 창을 닫으면 창을 숨기고, 편집 앱을 종료하면 편집 프로세스를 끝냅니다. Linux에서 창을 닫으면 편집 프로세스를 끝냅니다. 상태 메뉴의 MixRelay 열기로 돌아오세요.

백그라운드 상태 메뉴의 종료는 장치와 루프백을 중지하고 녹음 파일을 마무리합니다. MixRelay를 다시 열면 저장한 장치를 복원합니다. 저장한 전체 일시정지는 재개할 때까지 유지됩니다. 따로 일시정지하거나 정지한 레코더는 전체 재개만으로 시작하지 않습니다.
