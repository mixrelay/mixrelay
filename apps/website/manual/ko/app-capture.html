MIXRELAY / MANUAL

앱 오디오 캡처

실행 중인 앱을 캡처하고 그래프에서 오디오를 연결하세요.

사전 공개 초안입니다. 공개 다운로드와 구매는 아직 제공하지 않습니다. 현재 소스 빌드를 기준으로 작성했으며 아래에 표시한 환경의 설치본 검증은 남아 있습니다.

이 페이지 목차

  • 앱 선택
  • 소스 사용 불가와 원래 재생 경로

01

앱 선택

  1. 소스 앱을 열고 소리를 재생해 오디오 소스를 사용할 수 있게 하세요.
  2. MixRelay의 노드 추가 → 소스에서 실행 중인 앱 아래의 앱을 선택하세요.
  3. 출력 채널을 프로세서·출력·녹음기에 연결하세요. 필요하면 옵션의 입력 레벨을 조절하세요.

목록에는 발견한 앱이 표시되며 개별 브라우저 탭이나 창을 고르는 기능은 없습니다. 표시 이름을 바꿔도 캡처 대상은 바뀌지 않습니다. 물리 입력과 개별 앱 캡처 노드는 무료 입력 2개 한도를 함께 사용합니다.

02

소스 사용 불가와 원래 재생 경로

캡처에는 48 kHz와 해당 macOS 권한이 필요합니다. 노드가 오프라인이면 앱이 실행 중인지 확인하세요. 앱을 다시 선택하세요 메시지가 표시되면 노드의 앱 선택에서 원하는 소스를 고르세요. 일치하는 소스가 여러 개일 때 MixRelay가 임의로 대체하지 않습니다.

앱의 원래 재생 경로와 MixRelay 경로가 모두 들릴 수 있습니다. 소리가 겹치면 모니터링 경로를 확인하세요. MixRelay는 시스템 기본 출력을 바꾸지 않습니다. 캡처 경로에서 원음을 차단하는 경우 MixRelay가 소유한 경로만 제어합니다. 현재 UI에는 원래 앱 재생을 따로 바꾸는 토글이 없습니다.
