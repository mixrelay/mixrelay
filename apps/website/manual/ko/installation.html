MIXRELAY / MANUAL

시스템 요구사항과 설치

운영체제에 맞는 MixRelay 전체 설치 파일을 사용하세요. Driver를 따로 설치할 필요가 없습니다.

사전 공개 초안입니다. 공개 다운로드와 구매는 아직 제공하지 않습니다. 현재 소스 빌드를 기준으로 작성했으며 아래에 표시한 환경의 설치본 검증은 남아 있습니다.

이 페이지 목차

  • 지원 환경
  • macOS 설치
  • Gatekeeper 확인
  • Linux 설치

01

지원 환경

  • macOS 14.2 이상, Apple Silicon 또는 Intel. 설치 파일은 Universal 2입니다. 설치본으로 확인한 최신 주 버전은 macOS 27입니다.
  • Linux x86_64 또는 arm64. PipeWire 1.2 이상과 WirePlumber 0.5 이상이 실행되는 로그인한 사용자 세션이 필요합니다. 현재 패키지는 glibc 2.39를 요구합니다.

Linux 빌드와 코드 검사는 두 아키텍처의 Debian 13·Ubuntu 26.04·Kali rolling 및 x86_64 Arch에서 수행합니다. 모든 배포판의 설치를 확인했다는 뜻은 아닙니다. 기본 Ubuntu 24.04 오디오 패키지는 버전이 낮습니다. 일반 Linux 가상 머신은 지원하며 Docker 오디오 환경은 지원하지 않습니다. Windows는 지원하지 않습니다.

지원하는 모든 macOS 버전의 검증이 끝난 것은 아닙니다. 14.8.7 VM에서는 설치·서비스·가상 장치를 확인했지만 권한 대화상자와 실제 캡처는 확인하지 않았습니다. 14.2–14.7·15·26의 설치본 확인도 남아 있습니다.

02

macOS 설치

  1. 공개 다운로드가 시작되면 공식 MixRelay-Installer-VERSION.pkg를 받으세요.
  2. 녹음·통화 앱을 종료하세요. 설치 중 시스템 오디오가 잠시 끊깁니다.
  3. PKG를 여세요. App·Driver 구성요소 약관을 읽고 설치 프로그램의 계속·동의 단계를 따르세요. 요청 시 macOS 관리자 계정으로 설치를 승인하세요.
  4. 설치가 끝나면 /Applications/MixRelay.app을 여세요. 재부팅은 필요하지 않습니다.

편집 앱·백그라운드 오디오·가상 장치·Uninstall MixRelay.app을 함께 설치합니다. 구성요소 선택 단계는 없습니다. 기존 장치·그래프·설정·녹음·인증은 보존합니다.

03

Gatekeeper 확인

공개 macOS 패키지는 Developer ID 서명과 공증을 거쳐야 합니다. macOS가 다운로드한 소프트웨어를 열지 확인할 수 있습니다. 확인되지 않은 개발자·검증할 수 없는 패키지·손상·악성 소프트웨어 경고가 나타나면 중단하고 공식 패키지를 다시 받거나 지원팀에 문의하세요. 설치를 위해 Gatekeeper를 끄거나 격리 속성을 제거하지 마세요. Apple: Safely open apps on your Mac에서 관련 안내를 확인할 수 있습니다.

04

Linux 설치

배포판의 패키지 관리자로 의존성을 함께 설치하세요. 예시 파일명을 아키텍처에 맞게 다운로드한 패키지명으로 바꾸세요.

sudo apt install ./MixRelay_VERSION_ARCH.deb
sudo dnf install ./MixRelay-VERSION-1.ARCH.rpm
sudo pacman -U ./mix-relay-VERSION-1-x86_64.pkg.tar.zst

배포판에 맞는 명령 하나만 실행하세요. 패키지명은 mix-relay입니다. 일반 사용자로 앱 메뉴에서 MixRelay를 여세요. PipeWire 오디오는 root가 아닌 해당 사용자의 세션에서 실행됩니다. SDK나 수동 서비스 설정은 필요하지 않습니다. AppImage는 지원하는 설치·업데이트 경로가 아닙니다.
