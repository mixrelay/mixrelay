MixRelay를 열고 오디오 엔진이 준비되면 사용할 소스를 선택하세요.

사전 공개 초안입니다. 공개 다운로드와 구매는 아직 제공하지 않습니다. 현재 소스 빌드를 기준으로 작성했으며 아래에 표시한 환경의 설치본 검증은 남아 있습니다.

01

오디오 엔진 연결

오디오를 준비하는 동안 MixRelay에 연결 중 메시지가 표시됩니다. MixRelay가 필요합니다 메시지가 표시되면 제품 전체를 설치하세요. MixRelay를 업데이트해 주세요 메시지가 표시되면 설치된 제품을 업데이트하세요. MixRelay에 연결할 수 없습니다 메시지가 표시되면 설치 상태를 확인한 뒤 다시 연결을 누르세요.

무료 기능에는 구매 인증이 필요하지 않습니다. OS 선호 언어 중 첫 지원 언어를 사용하며, 없으면 영어를 사용합니다. 화면 테마에서 시스템·라이트·다크를 선택할 수 있습니다.

02

macOS 오디오 캡처와 마이크

앱 소스를 처음 사용할 때 macOS가 앱 또는 시스템 오디오 캡처 권한을 요청할 수 있습니다. 마이크나 다른 물리 오디오 입력을 사용할 때는 마이크 접근 권한을 요청할 수 있습니다. 해당 소스를 사용하려면 요청한 접근을 허용하세요. 두 권한은 별개이며 마이크 권한만 허용해도 앱 캡처가 활성화되지는 않습니다.

권한을 거부했다면 시스템 설정 → 개인정보 보호 및 보안을 여세요. 화면 및 시스템 오디오 녹음의 오디오 캡처 설정과 물리 입력의 마이크 설정을 확인하세요. 이름과 요청 문구는 macOS 버전에 따라 다릅니다. 요청한 MixRelay 항목의 접근을 허용하고 macOS가 재시작을 안내하면 따르세요. 이후 MixRelay에서 소스를 다시 시도하세요. Apple: Screen and system audio permissions에서 관련 안내를 확인할 수 있습니다.

Linux에서는 일반 PipeWire 세션을 사용합니다. 이 흐름에는 macOS 방식의 권한 요청이 없습니다.

03

첫 경로 만들기

  1. 기존 그래프를 선택하세요. 그래프가 없으면 새 그래프를 누르고 그래프 이름을 입력한 뒤 생성을 누르세요. 무료 기능에서는 그래프 1개를 사용할 수 있습니다.
  2. 노드 추가 → 소스에서 실행 중인 앱이나 오디오 입력을 선택하세요.
  3. 노드 추가 → 출력에서 오디오 출력을 선택하세요. 소스의 각 출력 채널을 출력 노드의 입력 채널에 연결하세요.
  4. 소스 앱에서 소리를 재생하거나 입력에 대고 말하세요. 미터와 출력 장치를 확인하세요.

OBS나 DAW로 믹스를 보내려면 MixRelay IO를 가상 출력으로 사용하고 받는 앱의 입력으로 선택하세요.
