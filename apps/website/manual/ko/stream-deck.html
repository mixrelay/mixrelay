MIXRELAY / MANUAL

Stream Deck 플러그인

macOS의 Stream Deck에서 그래프 노드를 제어하세요.

플러그인 패키지는 MixRelay 릴리스와 함께 배포합니다. Elgato Marketplace 설치는 등록이 공개된 뒤에 이용할 수 있습니다.

이 페이지 목차

  • 요구사항과 설정
  • 버튼·다이얼·녹음

01

요구사항과 설정

macOS 15.0 이상·Stream Deck 7.1 이상과 실행 중인 MixRelay가 필요합니다. Linux Stream Deck은 지원하지 않습니다. 플러그인은 비공개 로컬 연결을 사용하며 계정·LAN 페어링·공개 HTTP 서비스가 필요하지 않습니다.

  1. MixRelay 플러그인은 Elgato Marketplace에 출시될 예정입니다. 등록이 승인되고 공개되면 Marketplace 제품 페이지에서 설치하세요.
  2. MixRelay의 전원·음소거·볼륨·녹음 동작을 추가하세요.
  3. 속성창에서 대상 그래프와 해당 동작을 지원하는 노드를 선택하세요.

MixRelay 백그라운드 오디오를 실행해 두세요. 편집 창은 닫아도 됩니다. 삭제한 노드는 대상을 직접 다시 지정해야 합니다. 실패하거나 연결이 끊긴 명령은 나중에 실행하도록 쌓아 두지 않습니다.

02

버튼·다이얼·녹음

전원은 노드 처리를 켜거나 끕니다. 음소거는 처리를 유지하면서 출력을 끕니다. 꺼진 노드의 다른 조작을 사용하려면 먼저 전원을 켜세요.

볼륨 버튼은 증가·감소 방향과 0.5·1·2·3 dB 단위를 선택합니다. Stream Deck + 다이얼을 돌리면 같은 단위로 바뀝니다. 대상이 음소거를 지원하면 다이얼을 눌러 음소거합니다. 게인이 없는 노드는 볼륨 대상에 표시하지 않습니다.

녹음에는 녹음기 노드만 표시됩니다. 녹음·일시정지·정지를 선택하세요. 일시정지한 녹음에 녹음을 실행하면 같은 파일에 재개합니다. 녹음 폴더와 형식은 MixRelay 녹음기의 옵션을 사용하며 속성창에서는 읽기 전용입니다.
