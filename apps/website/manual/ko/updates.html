MIXRELAY / MANUAL

업데이트

MixRelay 전체를 하나의 제품으로 업데이트하세요. 다운로드와 설치는 직접 실행합니다.

사전 공개 초안입니다. 공개 다운로드와 구매는 아직 제공하지 않습니다. 현재 소스 빌드를 기준으로 작성했으며 아래에 표시한 환경의 설치본 검증은 남아 있습니다.

이 페이지 목차

  • 릴리스 확인
  • 업데이트 설치

01

릴리스 확인

앱이나 상태 메뉴의 업데이트 확인을 선택하세요. 시작 시와 24시간마다 자동으로도 확인합니다. 앱에는 설치 버전과 최신 릴리스가 표시됩니다. 아직 게시된 릴리스가 없습니다. 메시지는 공개 릴리스가 없다는 뜻입니다. 이 제품의 업데이트를 확인하지 못했습니다. 온라인일 때 다시 시도하세요. 메시지는 조회 실패입니다. 둘 다 최신 버전이라는 뜻은 아닙니다.

온라인에서 다시 확인을 사용하세요. 다운로드가 있으면 해당 다운로드 열기를 선택하세요. 링크를 열기 전에 목록을 다시 확인하며 자동으로 설치하지 않습니다.

02

업데이트 설치

중요한 작업은 .mix 사본으로 저장하세요. 녹음·통화 앱을 종료하고 설치 절차에 따라 새 전체 설치 파일을 실행하세요. Linux에서는 편집 앱을 종료하고 상태 메뉴의 종료로 백그라운드 오디오도 종료한 뒤 업데이트하세요. 패키지 훅은 실행 중인 MixRelay 프로세스가 있으면 거부합니다. macOS 설치 프로그램은 설치 과정에서 앱 역할의 종료를 요청합니다.

업데이트는 장치·그래프·설정·녹음·인증을 보존합니다. 편집 앱과 오디오 구성요소는 하나의 버전과 설치 파일을 사용합니다. Driver 업데이트를 따로 선택하지 않습니다. 설치 후 MixRelay를 다시 열고 설치 버전을 확인하세요.
