사용 안내서

MixRelay 설치·오디오 연결·녹음·설치본 관리를 안내합니다.

사전 공개 초안입니다. 공개 다운로드와 구매는 아직 제공하지 않습니다. 현재 소스 빌드를 기준으로 작성했으며 아래에 표시한 환경의 설치본 검증은 남아 있습니다.

01

안내서 목차

  1. 시스템 요구사항과 설치

    운영체제에 맞는 MixRelay 전체 설치 파일을 사용하세요. Driver를 따로 설치할 필요가 없습니다.

  2. 처음 실행과 권한

    MixRelay를 열고 오디오 엔진이 준비되면 사용할 소스를 선택하세요.

  3. 라우팅 작업 영역

    소스·프로세서·출력 노드로 그래프를 구성하세요. 케이블은 개별 채널 사이로 오디오를 전달합니다.

  4. 장치와 가상 장치

    MixRelay IO로 다른 앱과 오디오를 주고받으세요. 장치 형식과 녹음 파일 형식은 별개입니다.

  5. 앱 오디오 캡처

    실행 중인 앱을 캡처하고 그래프에서 오디오를 연결하세요.

  6. 녹음

    그래프에 연결한 신호를 RF64 WAV 파일로 녹음하세요.

  7. 내장 효과와 프리셋

    무료 기능에서도 내장 처리를 개수 제한 없이 사용할 수 있습니다.

  8. 외부 플러그인

    제작사의 설치 프로그램으로 효과를 설치한 뒤 MixRelay에서 검색하세요.

  9. Stream Deck 플러그인

    macOS의 Stream Deck에서 그래프 노드를 제어하세요.

  10. MIDI 컨트롤러

    macOS와 Linux에서 MIDI 컨트롤러로 노드를 제어합니다.

  11. 무료 기능과 라이선스

    무료 기능은 기간 제한 없이 사용할 수 있습니다. 유료 라이선스는 같은 설치본의 기능을 확장합니다.

  12. 업데이트

    MixRelay 전체를 하나의 제품으로 업데이트하세요. 다운로드와 설치는 직접 실행합니다.

  13. 제거

    제거 앱이나 Linux 패키지 관리자로 제품 전체를 제거하세요.

  14. 문제 해결과 진단

    저장된 작업을 바꾸거나 지우기 전에 현재 메시지와 신호 경로를 확인하세요.

  15. 지원 문의

    MixRelay·라이선스·환불·제품 편입 문의는 에코 비전 랩(Echo Vision Lab)으로 보내세요.
