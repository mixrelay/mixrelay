01

Einrichten und aufnehmen

  1. Wählen Sie Knoten hinzufügen → Ausgang → Rekorder. Verbinden Sie die Kanäle, die Sie aufnehmen möchten.
  2. Öffnen Sie Optionen. Legen Sie Kanäle fest und wählen Sie mit Ordner auswählen… den Aufnahmeordner.
  3. Wählen Sie die WAV-Abtastrate (Eingangsabtastrate übernimmt beim Start einer Aufnahme die Eingangsabtastrate) und die Bittiefe: PCM16, PCM24 oder Float32.
  4. Wählen Sie Aufnehmen. MixRelay erstellt den Dateinamen der Aufnahme. Verwenden Sie bei Bedarf Pausieren, Fortsetzen und Stoppen.

Stoppen Sie die Aufnahme, bevor Sie die Aufnahmeeinstellungen ändern. Während einer laufenden oder pausierten Aufnahme sind diese Einstellungen gesperrt. Jede Aufnahme ist eine einzelne RF64-.wav-Datei, auch bei Dateien über 4 GiB. Verwenden Sie ein Programm, das RF64 lesen kann. MixRelay teilt die Aufnahme nicht nach Dateigröße auf und bietet keine MP3-Aufnahme.

02

Eine Aufnahme pausieren und abschließen

Die Aktion Fortsetzen setzt die Aufnahme in derselben Datei fort. Eine Pause fügt keine Stille hinzu: Nehmen Sie 10 Sekunden auf, pausieren Sie 5 Sekunden und nehmen Sie weitere 10 Sekunden auf, um eine Datei mit 20 Sekunden zu erhalten. Aufnahmedauer zählt das in die Datei geschriebene Audio.

Die globale Aktion Pausieren pausiert auch aktive Rekorder. Die globale Aktion Fortsetzen startet keinen manuell pausierten oder bereits gestoppten Rekorder neu. Während einer globalen Pause können Sie mit Stoppen des Rekorders die Datei abschließen. Die Aktion Stoppen schließt den WAV-Header ab. Das Schließen des Editors lässt die Aufnahme weiterlaufen; das Beenden der Hintergrund-Audioverarbeitung schließt offene Aufnahmen ab.

03

Kostenlose und technische Grenzen

Kostenlos verfügbar sind ein Rekorder, bis zu zwei Kanäle und zwei Stunden aufgenommenes Audio pro Aufnahme. Pausenzeit zählt nicht mit. Beim Erreichen der Grenze wird die Datei regulär abgeschlossen und das Audio-Routing läuft weiter. Eine pausierte Aufnahme belegt weiterhin das Rekorderkontingent.

Die lizenzierte Engine unterstützt 1–8 Kanäle pro Rekorder und bis zu 16 Aufnahmesitzungen. Die zulässige Dauer wird beim Start einer Aufnahme festgelegt. Eine spätere Aktivierung verlängert keine kostenlose Aufnahme. Der Ablauf einer Lizenz verkürzt keine Aufnahme, die mit kostenpflichtigem Zugriff begonnen wurde. Starten Sie eine neue Aufnahme, um das aktuelle Lizenzkontingent zu nutzen.

Erscheint Aufnahmefehler, prüfen Sie den gewählten Ordner, Schreibrechte und freien Speicherplatz. Stoppen Sie und prüfen Sie die gespeicherte Datei, bevor Sie eine weitere Aufnahme beginnen.
