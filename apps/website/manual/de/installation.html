MIXRELAY / HANDBUCH

Systemanforderungen und Installation

Installieren Sie das vollständige MixRelay-Produkt für Ihr Betriebssystem. Eine separate Driver-Installation ist nicht nötig.

Vorläufige Fassung vor Veröffentlichung. Öffentliche Downloads und Käufe sind noch nicht verfügbar. Diese Anleitung beschreibt den aktuellen Build aus dem Quellcode. Das Verhalten nach der Installation muss in den unten genannten Umgebungen noch überprüft werden.

Auf dieser Seite

  • Unterstützte Umgebungen

01

Unterstützte Umgebungen

  • macOS 15.0 oder neuer, Apple Silicon oder Intel. Das Installationsprogramm ist Universal 2. macOS 27 ist die neueste Hauptversion, die mit einem installierten Build geprüft wurde.
  • Linux x86_64 oder arm64 in einer angemeldeten Benutzersitzung mit PipeWire 1.2 oder neuer und WirePlumber 0.5 oder neuer. Die aktuellen Pakete benötigen glibc 2.39.

Linux-Builds und Codetests decken Debian 13, Ubuntu 26.04 und Kali rolling auf beiden Architekturen sowie Arch auf x86_64 ab. Das bestätigt keine Installation auf jeder Distribution. Die unveränderten Audiopakete von Ubuntu 24.04 sind zu alt. Normale virtuelle Linux-Maschinen werden unterstützt; Docker-Audioumgebungen nicht. Windows wird nicht unterstützt.

Intel-Macs werden auf von Apple unterstützten Modellen mit macOS 15–26 unterstützt. Jede Version wird auf macOS 15 und 26 mit Apple Silicon und Intel sowie auf macOS 27 mit Apple Silicon installiert und geprüft. Nicht jede Patch-Version wird geprüft.

02

Unter macOS installieren

  1. Sobald öffentliche Downloads verfügbar sind, laden Sie das offizielle Paket MixRelay-Installer-VERSION.pkg herunter.
  2. Beenden Sie Aufnahme- und Telefonie-Apps. Die Installation unterbricht das Systemaudio kurz.
  3. Öffnen Sie das PKG. Lesen Sie die Vereinbarungen für die Komponenten App und Driver und folgen Sie dann den Schritten „Fortfahren“ und „Akzeptieren“ des Installationsprogramms. Autorisieren Sie die Installation auf Anfrage mit einem macOS-Administratorkonto.
  4. Öffnen Sie nach der Installation /Applications/MixRelay/MixRelay.app. Ein Neustart ist nicht erforderlich.

Das Paket installiert Editor, Hintergrund-Audioverarbeitung, virtuelle Geräte und Uninstall MixRelay.app gemeinsam. Eine Komponentenauswahl gibt es nicht. Vorhandene Geräte, Graphen, Einstellungen, Aufnahmen und Authentifizierung bleiben erhalten.

03

Gatekeeper-Prüfungen

Öffentliche macOS-Pakete müssen mit Developer ID signiert und notarisiert sein. macOS kann eine Bestätigung zum Öffnen heruntergeladener Software verlangen. Meldet macOS einen unbekannten Entwickler, ein nicht überprüfbares Paket, eine Beschädigung oder Schadsoftware, brechen Sie ab und laden Sie ein neues offizielles Paket herunter oder kontaktieren Sie den Support. Deaktivieren Sie Gatekeeper nicht und entfernen Sie keine Quarantäneattribute als Installationsschritt. Siehe Apples Hinweise zum Öffnen heruntergeladener Apps.

04

Unter Linux installieren

Verwenden Sie den Paketmanager Ihrer Distribution, damit er Abhängigkeiten auflöst. Ersetzen Sie den Beispieldateinamen durch das heruntergeladene Paket für Ihre Architektur.

sudo apt install ./MixRelay_VERSION_ARCH.deb
sudo dnf install ./MixRelay-VERSION-1.ARCH.rpm
sudo pacman -U ./mix-relay-VERSION-1-x86_64.pkg.tar.zst

Führen Sie nur den Befehl für Ihre Distribution aus. Der Paketname lautet mix-relay. Starten Sie MixRelay als normaler Benutzer aus dem Anwendungsmenü. PipeWire-Audio läuft in dessen Sitzung, niemals als root. Ein SDK oder manuelles Einrichten von Diensten ist nicht nötig. AppImage ist kein unterstützter Installations- oder Updateweg.
