MIXRELAY / HANDBUCH

Updates

Aktualisieren Sie MixRelay als ein vollständiges Produkt. Updates werden manuell heruntergeladen und installiert.

Vorläufige Fassung vor Veröffentlichung. Öffentliche Downloads und Käufe sind noch nicht verfügbar. Diese Anleitung beschreibt den aktuellen Build aus dem Quellcode. Das Verhalten nach der Installation muss in den unten genannten Umgebungen noch überprüft werden.

Auf dieser Seite

  • Nach einer Veröffentlichung suchen
  • Ein Update installieren

01

Nach einer Veröffentlichung suchen

Wählen Sie in der App oder im Statusmenü Nach Updates suchen. MixRelay prüft außerdem beim Start und alle 24 Stunden auf Updates. Die App zeigt Installiert und Neueste Version. Es wurde noch keine Version veröffentlicht. bedeutet, dass es noch keine öffentliche Veröffentlichung gibt. Dieses Produkt konnte nicht überprüft werden. Versuchen Sie es erneut, sobald Sie online sind. bedeutet, dass die Prüfung fehlgeschlagen ist. Beides bestätigt nicht, dass die Installation aktuell ist.

Verwenden Sie online Erneut prüfen. Ist ein Download verfügbar, öffnen Sie ihn über die zugehörige Downloadaktion. MixRelay prüft den Katalog erneut, bevor der Link geöffnet wird. Es erfolgt keine automatische Installation.

02

Ein Update installieren

Speichern Sie wichtige Arbeit als .mix-Kopie. Beenden Sie Aufnahme- und Telefonie-Apps und führen Sie das neue vollständige Installationsprogramm nach den Installationsschritten aus. Beenden Sie unter Linux vor dem Update sowohl den Editor als auch die Hintergrund-Audioverarbeitung über Beenden im Statusmenü. Die Paket-Hooks verweigern die Ausführung bei aktiven MixRelay-Prozessen. Unter macOS fordert das Installationsprogramm im Rahmen der Installation das Beenden der laufenden App-Komponenten an.

Updates erhalten Geräte, Graphen, Einstellungen, Aufnahmen und Authentifizierung. Editor und Audiokomponenten haben eine gemeinsame Version und ein gemeinsames Installationsprogramm. Separate Driver-Updates werden nicht ausgewählt. Öffnen Sie MixRelay nach der Installation erneut und prüfen Sie die installierte Version.
