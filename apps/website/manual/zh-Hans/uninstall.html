MIXRELAY / 手册

卸载

使用卸载程序或 Linux 包管理器移除完整产品。

发布前草稿。目前尚不提供公开下载或购买。本手册介绍当前源代码构建版本的行为；在下文所列环境中，仍需验证安装后的实际行为。

本页内容

  • 移除前的准备
  • 在 macOS 上移除
  • 在 Linux 上移除

01

移除前的准备

请将需要保留的工作保存为 .mix 文件。停止录音，退出通话和录音应用。如需解除此电脑的付费激活，请在移除前联网使用取消此设备的激活。卸载本身不能确认服务器端已停用。

02

在 macOS 上移除

  1. 打开 /Applications/MixRelay/Uninstall MixRelay.app。
  2. 如需保留虚拟设备设置，请不要勾选 删除已保存的 MixRelay 设置。
  3. 选择 移除 MixRelay，并批准 macOS 管理员授权请求。当前移除对话框虽然使用这些 Driver 标签，但会移除完整产品。
  4. 等待确认完成。移除会停止设备和回环，并短暂中断系统音频。

可选删除项只会移除已保存的设备设置。在 macOS 上，音频图、录音、已导出的工作和付费认证均会保留。仅将编辑器应用移至废纸篓不会移除已安装的音频组件。如果移除失败，请阅读消息并检查当前安装状态后再重试；某些组件可能已被移除。取消授权不会改变产品。

03

在 Linux 上移除

退出编辑器，并在后台状态菜单中选择 退出。以普通用户身份打开已安装的 卸载 MixRelay 应用入口。如需保留已保存的音频图和设置，请不要勾选对应的删除选项。卸载程序使用当前会话的正常 polkit 认证代理和包管理器。成功移除后，会清除本地付费许可登录信息；录音和已导出的项目仍会保留。

也可以直接移除 mix-relay 软件包。仅选择适用于您发行版的命令。直接通过包管理器移除会保留各用户的设置和本地认证信息。

sudo apt remove mix-relay
sudo dnf remove mix-relay
sudo pacman -R mix-relay

如果无法显示授权界面，请检查桌面会话是否有 polkit 认证代理。如果应用已移除但清理失败，请按显示的恢复消息操作。请勿删除无关的音频服务或用户文件夹。
