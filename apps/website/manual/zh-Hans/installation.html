MIXRELAY / 手册

系统要求与安装

安装适用于您操作系统的完整 MixRelay 产品，无需单独安装 Driver。

发布前草稿。目前尚不提供公开下载或购买。本手册介绍当前源代码构建版本的行为；在下文所列环境中，仍需验证安装后的实际行为。

本页内容

  • 支持的环境
  • 在 macOS 上安装
  • Gatekeeper 检查
  • 在 Linux 上安装

01

支持的环境

  • macOS 14.2 或更高版本，Apple Silicon 或 Intel。安装程序为 Universal 2。通过已安装构建版本检查的最新主要版本为 macOS 27。
  • Linux x86_64 或 arm64，在已登录的用户会话中使用 PipeWire 1.2 或更高版本及 WirePlumber 0.5 或更高版本。当前软件包要求 glibc 2.39。

Linux 构建与代码测试覆盖两种架构的 Debian 13、Ubuntu 26.04 和 Kali rolling，以及 x86_64 的 Arch。这不代表已验证在所有发行版上的安装。未经更改的 Ubuntu 24.04 音频软件包版本过旧。支持普通 Linux 虚拟机，不支持 Docker 音频环境。不支持 Windows。

macOS 检查未覆盖所有受支持的系统版本：已检查 14.8.7 虚拟机的安装、服务及虚拟设备，但未检查其权限对话框和实时采集。14.2–14.7、15 和 26 的安装检查仍未完成。

02

在 macOS 上安装

  1. 公开下载开放后，获取官方的 MixRelay-Installer-VERSION.pkg。
  2. 退出录音和通话应用。安装会短暂中断系统音频。
  3. 打开 PKG。阅读 App 和 Driver 组件协议，然后按安装器中的“继续”和“同意”步骤操作。出现提示时，使用 macOS 管理员账户授权安装。
  4. 安装完成后，打开 /Applications/MixRelay/MixRelay.app。无需重新启动。

此软件包会一起安装编辑器、后台音频组件、虚拟设备及 Uninstall MixRelay.app，不提供组件选择。现有设备、音频图、设置、录音和认证信息均会保留。

03

Gatekeeper 检查

公开发布的 macOS 软件包必须经过 Developer ID 签名和公证。macOS 可能要求您确认是否打开下载的软件。如果 macOS 提示开发者身份不明、无法验证软件包、文件已损坏或存在恶意软件，请停止操作，重新获取官方软件包或联系支持。请勿为安装而禁用 Gatekeeper 或移除隔离属性。参阅 Apple 关于打开已下载应用的说明。

04

在 Linux 上安装

请使用发行版的包管理器，以便自动解决依赖关系。将示例文件名替换为您下载的、适用于相应架构的软件包文件名。

sudo apt install ./MixRelay_VERSION_ARCH.deb
sudo dnf install ./MixRelay-VERSION-1.ARCH.rpm
sudo pacman -U ./mix-relay-VERSION-1-x86_64.pkg.tar.zst

仅运行适用于您发行版的命令。软件包名为 mix-relay。请以普通用户身份从应用菜单启动 MixRelay。PipeWire 音频在该用户的会话中运行，切勿以 root 身份运行。无需 SDK 或手动设置服务。AppImage 不是受支持的安装或更新方式。
