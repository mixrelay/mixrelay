MIXRELAY / 手册

Stream Deck 插件

在 macOS 上通过 Stream Deck 控制音频图节点。

发布前草稿。目前尚不提供公开下载或购买。本手册介绍当前源代码构建版本的行为；在下文所列环境中，仍需验证安装后的实际行为。

本页内容

  • 要求与设置
  • 按键、旋钮与录音

01

要求与设置

要求 macOS 14.2 或更高版本、Stream Deck 6.6 或更高版本，并且 MixRelay 正在运行。不提供 Linux Stream Deck 支持。插件使用私有本地连接，无需账户、局域网配对或公开 HTTP 服务。

  1. 官方插件包可用后，用 Stream Deck 打开其 .streamDeckPlugin 文件。目前尚未提供公开下载。
  2. 添加一个 MixRelay 的 电源、静音、音量 或 录音 操作。
  3. 在属性检查器中，选择目标音频图和支持该操作的节点。

请保持 MixRelay 后台音频运行，可以关闭编辑器窗口。节点被删除后，必须手动重新指定目标。失败或断线时的命令不会排队等待之后执行。

02

按键、旋钮与录音

电源 开启或关闭节点处理。静音 在保持处理的同时使输出静音。节点关闭时，必须先开启电源，其他控件才能操作它。

对于 音量 按钮，选择增加或减少，以及 0.5、1、2 或 3 dB 的步长。旋转 Stream Deck + 旋钮时，音量按同样的步长变化。如果目标支持静音，按下旋钮即可静音。没有增益的节点不能作为音量控制目标。

录音 仅列出录音器节点。可选择录音、暂停或停止。选择录音会继续已有的暂停录音。录音文件夹和格式来自 MixRelay 录音器的选项，在属性检查器中只读。
