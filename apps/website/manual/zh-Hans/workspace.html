MIXRELAY / 手册

路由工作区

使用音源、处理器和输出节点构建音频图。连线在各个通道之间传送音频。

发布前草稿。目前尚不提供公开下载或购买。本手册介绍当前源代码构建版本的行为；在下文所列环境中，仍需验证安装后的实际行为。

本页内容

  • 音频图、节点与保存
  • 连接与映射通道
  • 不拖动也能连接
  • 关闭、静音、旁通、暂停与退出

01

音频图、节点与保存

使用 新建音频图 创建音频图，通过 添加节点 添加 音源、处理器 或 输出。在 音频图 中选择要编辑的音频图。选择一个音频图不会关闭其他音频图。有许可时，多个音频图可以同时运行。

打开节点的 选项 可查看其可用参数。双击节点名称、在节点获得焦点时按 F2，或使用菜单中的 更改显示名称 可修改显示名称。显示名称仅影响当前节点，清空即可恢复原名。

编辑内容和布局会自动保存。出现保存警告时，更改可能在重新启动后丢失。如需可携带的工作区，请使用 文件 → 保存 或 另存为… 写入 .mix 文件。新建工作区 和 打开… 会在替换当前内容前询问确认。工作区文件不会安装缺失的设备或插件。

02

连接与映射通道

将输出端口拖到输入端口。立体声需要连接两个通道。按住 Shift 可在同一节点上选择更多输出通道，再将所选通道拖至目标的第一个通道；目标通道之间的相对偏移会保留。按 Escape 可取消并清除通道选择。

右键点击连线可选择 删除连线。端口菜单提供 断开通道 或 断开所选通道。选中节点或连线后，按 Delete 或 Backspace 也可删除。适配音频图视图 可将整个音频图显示在视图中。在 macOS 上使用 Command+Z、在 Linux 上使用 Ctrl+Z 撤销音频图编辑；同时按住 Shift 可重做。

删除音频图 会停止该音频图的音频与录音。删除音频图无法撤销，已保存的工作区文件仍会保留。

03

不拖动也能连接

  1. 按 Tab 将焦点移至音源节点。按 Enter 或 Space 选中节点。方向键可移动选中的节点，按住 Shift 可增大移动步幅。
  2. 按 Shift+F10 或上下文菜单键，然后选择 连接声道…。
  3. 选择 起始输出声道 和 声道数，或保留已有的通道选择。再选择 目标 和 起始输入声道。
  4. 查看 预览，包括跳过的连接及其原因。选择 连接，或选择 取消 以保持音频图不变。

焦点位于连线或画布时，同样可以使用这些上下文菜单快捷键。节点内部控件保留各自的键盘操作方式。按 Escape 可关闭菜单和对话框。

04

关闭、静音、旁通、暂停与退出

  • 关闭节点电源会禁用处理，并阻断其信号。
  • 静音会继续处理，但使节点输出无声。
  • 效果器的 旁通 会保留设置并传递干声。
  • 页脚或状态菜单中的 暂停 会暂停所有音频图和正在进行的录音。继续 从当前音频继续；暂停期间的音频会被丢弃。虚拟设备的 ID、名称和格式保持不变。

关闭编辑器后，路由、效果、采集和录音仍会在后台运行。在 macOS 上，关闭窗口会将其隐藏，退出编辑器则会结束编辑器进程。在 Linux 上，关闭窗口会结束编辑器进程。使用状态菜单中的 打开 MixRelay 可返回编辑器。

后台状态菜单中的 退出 会停止设备和回环，并完成录音文件的收尾。重新打开 MixRelay 会恢复已保存的设备。已保存的全局暂停状态会保持到您继续音频为止；手动暂停或已停止的录音器不会仅因您继续所有音频而开始录音。
