MIXRELAY / 手册

首次启动与权限

打开 MixRelay，等待音频引擎就绪，然后选择要使用的音源。

发布前草稿。目前尚不提供公开下载或购买。本手册介绍当前源代码构建版本的行为；在下文所列环境中，仍需验证安装后的实际行为。

本页内容

  • 连接音频引擎
  • macOS 音频采集与麦克风权限
  • 建立第一条音频路由

01

连接音频引擎

准备音频时会显示 正在连接 MixRelay。如果显示 需要 MixRelay，请安装完整产品。如果显示 请更新 MixRelay，请更新已安装的产品。如果显示 无法连接 MixRelay，请检查安装情况后选择 重新连接。

免费版无需购买或激活。应用按操作系统的语言偏好顺序，使用第一个受支持的语言；若无匹配项，则使用英语。外观 提供 跟随系统、浅色 和 深色 选项。

02

macOS 音频采集与麦克风权限

首次使用应用音源时，macOS 可能请求采集应用或系统音频的权限。使用麦克风或其他物理音频输入时，macOS 可能请求麦克风访问权限。如需使用该音源，请允许相应访问。这是两项独立权限；仅允许麦克风访问不会启用应用音频采集。

如果之前拒绝了访问，请打开“系统设置”→“隐私与安全性”。在“屏幕与系统音频录制”下检查音频采集设置，并在“麦克风”中检查物理输入权限。标签和提示会随 macOS 版本变化。请为发起请求的 MixRelay 项目启用访问，并按 macOS 的指示重新启动。然后在 MixRelay 中重试该音源。参阅 Apple 的屏幕与系统音频权限指南。

在 Linux 上，音源使用正常的 PipeWire 会话，此流程不包含 macOS 式的权限提示。

03

建立第一条音频路由

  1. 选择现有音频图；如果没有，选择 新建音频图，输入 音频图名称，然后选择 创建。免费版允许使用一个音频图。
  2. 通过 添加节点 → 音源 选择正在运行的应用或音频输入。
  3. 通过 添加节点 → 输出 选择音频输出。将音源的各个输出通道连接到输出节点的输入通道。
  4. 在源应用中播放音频，或对着输入设备说话。检查电平表和输出设备。

如需将混音发送至 OBS 或 DAW，请将 MixRelay IO 用作虚拟输出，并在接收应用中将其选为输入。
