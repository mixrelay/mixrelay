Contacter l’assistance

Écrivez à support@rawsector.com. L’objectif est d’apporter une première réponse sous deux jours ouvrés selon le calendrier coréen. Il s’agit d’un délai de réponse visé, pas d’un délai de résolution garanti. Les ventes publiques et le service d’assistance par e-mail sont encore en préparation.

Pour signaler un problème, indiquez la version de MixRelay, la version et l’architecture du système, le résultat attendu, les étapes de reproduction et le message d’erreur exact. Ajoutez les versions pertinentes des périphériques ou plug-ins et, si utile, un rapport de diagnostic. Les captures d’écran doivent montrer l’état concerné ; retirez les informations privées sans rapport avec le problème.

Pour un remboursement ou l’activation d’un ordinateur inaccessible, indiquez la référence d’achat et expliquez votre demande. N’envoyez pas de mots de passe, de données de carte bancaire ou de clé de licence complète. Pour une intégration ou une redistribution, décrivez le produit et le mode de distribution envisagés.
