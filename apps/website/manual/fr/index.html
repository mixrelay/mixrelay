MIXRELAY / MANUEL

Manuel d’utilisation

Configurez MixRelay, connectez vos sources audio, enregistrez et gérez votre installation.

Version provisoire avant publication. Les téléchargements et les achats ne sont pas encore ouverts au public. Ces instructions décrivent la version actuelle compilée à partir du code source. Le comportement après installation reste à vérifier dans les environnements indiqués ci-dessous.

01

Chapitres du manuel

  1. Configuration requise et installation

    Installez le produit MixRelay complet pour votre système d’exploitation. Aucune installation Driver séparée n’est nécessaire.

  2. Premier lancement et autorisations

    Ouvrez MixRelay, attendez son moteur audio, puis sélectionnez les sources à utiliser.

  3. Espace de routage

    Créez un graphe avec des nœuds source, processeur et sortie. Les câbles transportent l’audio entre les canaux individuels.

  4. Périphériques et points de terminaison virtuels

    Échangez de l’audio avec d’autres applications via MixRelay IO. Le format du périphérique est indépendant du format d’enregistrement.

  5. Capture audio des applications

    Capturez une application en cours d’exécution et acheminez son audio dans votre graphe.

  6. Enregistrement

    Enregistrez tout signal connecté du graphe dans un fichier RF64 WAV.

  7. Effets intégrés et préréglages

    Les traitements intégrés sont disponibles sans limite d’instances dans la version gratuite.

  8. Plug-ins externes

    Installez les effets avec le programme d’installation de leur fournisseur, puis lancez leur recherche dans MixRelay.

  9. Plug-in Stream Deck

    Contrôlez les nœuds de vos graphes avec Stream Deck sur macOS.

  10. Contrôleurs MIDI

    Pilotez les nœuds par MIDI sur macOS et Linux.

  11. Version gratuite et licences

    La version gratuite n’a pas de limite de durée. Une licence payante étend les possibilités du même produit installé.

  12. Mises à jour

    Mettez à jour MixRelay comme un produit complet. Les mises à jour se téléchargent et s’installent manuellement.

  13. Désinstallation

    Supprimez le produit complet avec son programme de désinstallation ou le gestionnaire de paquets Linux.

  14. Dépannage et diagnostic

    Vérifiez le message actuel et le trajet du signal avant de modifier ou de supprimer le travail enregistré.

  15. Contacter l’assistance

    Contactez Echo Vision Lab au sujet de MixRelay, des licences, des remboursements ou de l’intégration du produit.
