MIXRELAY / MANUEL

Configuration requise et installation

Installez le produit MixRelay complet pour votre système d’exploitation. Aucune installation Driver séparée n’est nécessaire.

Version provisoire avant publication. Les téléchargements et les achats ne sont pas encore ouverts au public. Ces instructions décrivent la version actuelle compilée à partir du code source. Le comportement après installation reste à vérifier dans les environnements indiqués ci-dessous.

01

Environnements pris en charge

  • macOS 15.0 ou ultérieur, Apple Silicon ou Intel. Le programme d’installation est Universal 2. macOS 27 est la dernière version majeure vérifiée avec une version installée.
  • Linux x86_64 ou arm64, dans une session utilisateur connectée avec PipeWire 1.2 ou ultérieur et WirePlumber 0.5 ou ultérieur. Les paquets actuels nécessitent glibc 2.39.

Les compilations et tests de code Linux couvrent Debian 13, Ubuntu 26.04 et Kali rolling sur les deux architectures, ainsi qu’Arch sur x86_64. Cela ne confirme pas l’installation sur toutes les distributions. Les paquets audio d’Ubuntu 24.04 sans modification sont trop anciens. Les machines virtuelles Linux normales sont prises en charge ; les environnements audio Docker ne le sont pas. Windows n’est pas pris en charge.

Les Mac Intel sont pris en charge sur les modèles pris en charge par Apple qui exécutent macOS 15 à 26. Chaque version est installée et vérifiée sur macOS 15 et 26 avec Apple Silicon et Intel, ainsi que sur macOS 27 avec Apple Silicon. Toutes les versions correctives ne sont pas vérifiées.

02

Installer sur macOS

  1. Lorsque les téléchargements publics seront ouverts, obtenez le paquet officiel MixRelay-Installer-VERSION.pkg.
  2. Quittez les applications d’enregistrement et d’appel. L’installation interrompt brièvement l’audio système.
  3. Ouvrez le PKG. Lisez les accords des composants App et Driver, puis suivez les étapes Continuer et Accepter du programme d’installation. Autorisez l’installation avec un compte administrateur macOS lorsque cela vous est demandé.
  4. Après l’installation, ouvrez /Applications/MixRelay/MixRelay.app. Aucun redémarrage n’est nécessaire.

Le paquet installe ensemble l’éditeur, l’audio en arrière-plan, les périphériques virtuels et Uninstall MixRelay.app. Il n’y a pas de sélection des composants. Les périphériques, graphes, réglages, enregistrements et authentification existants sont conservés.

03

Vérifications Gatekeeper

Les paquets macOS publics doivent être signés avec Developer ID et notariés. macOS peut demander de confirmer l’ouverture d’un logiciel téléchargé. Si macOS signale un développeur non identifié, un paquet invérifiable, un fichier endommagé ou un logiciel malveillant, arrêtez et obtenez un nouveau paquet officiel ou contactez l’assistance. Ne désactivez pas Gatekeeper et ne supprimez pas les attributs de quarantaine pour installer. Consultez les conseils Apple pour ouvrir des applications téléchargées.

04

Installer sous Linux

Utilisez le gestionnaire de paquets de votre distribution pour résoudre les dépendances. Remplacez le nom de fichier d’exemple par celui du paquet téléchargé pour votre architecture.

sudo apt install ./MixRelay_VERSION_ARCH.deb
sudo dnf install ./MixRelay-VERSION-1.ARCH.rpm
sudo pacman -U ./mix-relay-VERSION-1-x86_64.pkg.tar.zst

Exécutez uniquement la commande correspondant à votre distribution. Le nom du paquet est mix-relay. Lancez MixRelay depuis le menu des applications avec votre compte utilisateur habituel. L’audio PipeWire fonctionne dans cette session, jamais en tant que root. Aucun SDK ni réglage manuel des services n’est nécessaire. AppImage n’est pas une méthode d’installation ou de mise à jour prise en charge.
