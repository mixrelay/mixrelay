MIXRELAY / MANUEL

Plug-ins externes

Installez les effets avec le programme d’installation de leur fournisseur, puis lancez leur recherche dans MixRelay.

Version provisoire avant publication. Les téléchargements et les achats ne sont pas encore ouverts au public. Ces instructions décrivent la version actuelle compilée à partir du code source. Le comportement après installation reste à vérifier dans les environnements indiqués ci-dessous.

01

Formats par plateforme

  • macOS : VST3, CLAP, AU et AUv3.
  • Linux : VST3, CLAP et LV2.

La liste contient les effets audio qui passent les vérifications de détection et de configuration des canaux. Les instruments et les fonctions MIDI ne sont pas proposés. La prise en charge d’un format ne garantit pas le fonctionnement de tous les plug-ins, architectures ou configurations de canaux. La version gratuite autorise deux instances de plug-ins externes, y compris les instances désactivées. Le nombre d’effets détectés n’est pas limité.

02

Rechercher et utiliser un effet

  1. Installez le plug-in adapté à votre plateforme et à votre architecture en suivant les instructions du fournisseur.
  2. Dans Ajouter un nœud → Processeur, choisissez Rechercher à nouveau les effets audio. Pour un emplacement VST3, CLAP ou LV2 personnalisé, choisissez Ajouter un dossier de plug-ins….
  3. Sélectionnez un effet détecté directement dans le menu Processeur. Sa description indique le format et le fournisseur. Vérifiez la Configuration des canaux et connectez les ports principaux, de sidechain ou auxiliaires nécessaires.
  4. Les paramètres exposés sont accessibles dans les Options du nœud. Un nouveau nœud de plug-in ouvre une fois son éditeur natif, s’il en possède un. Utilisez Ouvrir pour le rouvrir.

Sous Linux, les éditeurs natifs nécessitent X11 ou XWayland. L’absence d’éditeur ne crée pas de fenêtre native générique de remplacement. Utilisez les paramètres exposés lorsqu’ils sont disponibles.

03

Erreurs de recherche, d’éditeur et de format

Si Recherche d’effets incomplète apparaît, ouvrez Problèmes de recherche et Détails techniques. Les effets auparavant disponibles restent dans la liste si une étape de recherche échoue. Corrigez l’installation ou le dossier, puis utilisez Réessayer ou relancez la recherche.

Si un plug-in a planté, utilisez Réessayer le plug-in planté : … lorsque cette action est proposée. Si un éditeur est indisponible, lisez la raison précise, par exemple l’absence d’éditeur natif ou de X11/XWayland. Certaines sessions AU/VST/LV2 refusent les changements de format en cours d’exécution, car le transfert de l’état natif des préréglages n’est pas implémenté. La session actuelle est conservée ; ne supposez pas que le format demandé a été appliqué.
