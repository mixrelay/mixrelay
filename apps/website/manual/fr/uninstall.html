MIXRELAY / MANUEL

Désinstallation

Supprimez le produit complet avec son programme de désinstallation ou le gestionnaire de paquets Linux.

Version provisoire avant publication. Les téléchargements et les achats ne sont pas encore ouverts au public. Ces instructions décrivent la version actuelle compilée à partir du code source. Le comportement après installation reste à vérifier dans les environnements indiqués ci-dessous.

01

Avant la désinstallation

Enregistrez le travail à conserver dans un fichier .mix. Arrêtez les enregistrements et quittez les applications d’appel et d’enregistrement. Pour libérer l’activation payante de cet ordinateur, utilisez Désactiver ce périphérique en ligne avant la désinstallation. La désinstallation ne confirme pas la désactivation côté serveur.

02

Désinstaller sur macOS

  1. Ouvrez /Applications/MixRelay/Uninstall MixRelay.app.
  2. Laissez l’option Supprimer les paramètres MixRelay enregistrés décochée pour conserver les réglages des périphériques virtuels.
  3. Choisissez Supprimer MixRelay et acceptez la demande d’autorisation administrateur de macOS. La boîte de dialogue actuelle utilise ces intitulés Driver, mais supprime le produit complet.
  4. Attendez la confirmation de fin. La désinstallation arrête les périphériques et le bouclage et interrompt brièvement l’audio système.

La suppression facultative ne concerne que les paramètres de périphérique enregistrés. Sur macOS, les graphes, enregistrements, travaux exportés et authentification payante sont conservés. Déplacer uniquement l’éditeur dans la corbeille ne supprime pas les composants audio installés. En cas d’échec, lisez le message et vérifiez l’installation actuelle avant de réessayer ; certains composants ont peut-être déjà été supprimés. Annuler l’autorisation laisse le produit inchangé.

03

Désinstaller sous Linux

Quittez l’éditeur et choisissez Quitter dans le menu d’état en arrière-plan. Ouvrez l’entrée d’application installée Désinstaller MixRelay avec votre compte utilisateur habituel. Laissez l’option de suppression des graphes et réglages enregistrés décochée pour conserver ces fichiers. Le programme de désinstallation utilise l’agent d’authentification polkit habituel de la session et le gestionnaire de paquets. Une suppression réussie efface la connexion locale à la licence payante ; les enregistrements et projets exportés sont conservés.

Vous pouvez aussi supprimer directement le paquet mix-relay. Choisissez uniquement la commande correspondant à votre distribution. La suppression directe par le gestionnaire de paquets conserve les réglages par utilisateur et l’authentification locale.

sudo apt remove mix-relay
sudo dnf remove mix-relay
sudo pacman -R mix-relay

Si la demande d’autorisation ne peut pas apparaître, vérifiez que la session de bureau possède un agent d’authentification polkit. Si l’application a été supprimée mais que le nettoyage a échoué, suivez le message de récupération affiché. Ne supprimez pas de services audio ou dossiers utilisateur sans rapport avec MixRelay.
