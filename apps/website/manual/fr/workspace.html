MIXRELAY / MANUEL

Espace de routage

Créez un graphe avec des nœuds source, processeur et sortie. Les câbles transportent l’audio entre les canaux individuels.

Version provisoire avant publication. Les téléchargements et les achats ne sont pas encore ouverts au public. Ces instructions décrivent la version actuelle compilée à partir du code source. Le comportement après installation reste à vérifier dans les environnements indiqués ci-dessous.

01

Graphes, nœuds et enregistrement

Utilisez Nouveau graphe pour créer un graphe et Ajouter un nœud pour ajouter Source, Processeur ou Sortie. Sélectionnez un graphe dans Graphes pour le modifier. La sélection ne désactive pas les autres graphes. Avec une licence, plusieurs graphes peuvent fonctionner ensemble.

Ouvrez les Options d’un nœud pour accéder à ses paramètres disponibles. Double-cliquez sur son nom, appuyez sur F2 lorsque le nœud a le focus, ou utilisez Renommer l’affichage dans son menu. Un nom affiché ne modifie que ce nœud. Effacez-le pour rétablir le nom d’origine.

Les modifications et la disposition sont enregistrées automatiquement. Un avertissement d’enregistrement signifie qu’elles pourraient être perdues après un redémarrage. Pour un espace de travail portable, utilisez Fichier → Enregistrer ou Enregistrer sous… pour écrire un fichier .mix. Nouvel espace de travail et Ouvrir… demandent confirmation avant de remplacer le contenu actuel. Un fichier d’espace de travail n’installe pas les périphériques ou plug-ins manquants.

02

Connecter et affecter les canaux

Faites glisser un port de sortie vers un port d’entrée. Pour une paire stéréo, connectez les deux canaux. Maintenez Shift pour sélectionner d’autres canaux de sortie sur le même nœud, puis faites glisser la sélection vers le premier canal de destination. Le décalage des canaux de destination est conservé. Appuyez sur Escape pour annuler et effacer la sélection des canaux.

Faites un clic droit sur un câble pour choisir Supprimer le câble. Le menu d’un port propose Déconnecter le canal ou Déconnecter les canaux sélectionnés. Sélectionnez un nœud ou un câble et appuyez sur Delete ou Backspace pour le supprimer. Ajuster la vue au graphe affiche le graphe dans la vue. Utilisez Command+Z sur macOS ou Ctrl+Z sous Linux pour annuler les modifications du graphe ; ajoutez Shift pour les rétablir.

Supprimer le graphe arrête le traitement audio et les enregistrements du graphe. Dans la liste des graphes, Command+Z sur macOS ou Ctrl+Z sur Linux annule la suppression ; ajoutez Shift pour la rétablir. Les fichiers enregistrés sont conservés.

03

Connecter sans faire glisser

  1. Utilisez Tab pour placer le focus sur le nœud source. Enter ou Space le sélectionne. Les flèches déplacent le nœud sélectionné ; maintenez Shift pour des pas plus grands.
  2. Appuyez sur Shift+F10 ou la touche Menu contextuel, puis choisissez Connecter des canaux….
  3. Choisissez Premier canal de sortie et Nombre de canaux, ou conservez une sélection de canaux existante. Choisissez Destination et Premier canal d’entrée.
  4. Lisez Aperçu, y compris les connexions ignorées et leurs raisons. Choisissez Connecter, ou Annuler pour laisser le graphe inchangé.

Les mêmes touches de menu contextuel fonctionnent sur un câble ou le canevas ayant le focus. Les commandes à l’intérieur d’un nœud conservent leur propre comportement au clavier. Escape ferme les menus et boîtes de dialogue.

04

Désactivation, coupure du son, contournement, pause et fermeture

  • La commande marche/arrêt d’un nœud désactive son traitement et bloque son signal lorsqu’il est désactivé.
  • Couper le son maintient le traitement et coupe la sortie du nœud.
  • Le Contournement d’un effet laisse passer l’audio non traité tout en conservant ses paramètres.
  • Mettre en pause dans le pied de fenêtre ou le menu d’état met en pause tous les graphes et enregistrements actifs. Reprendre utilise l’audio actuel. L’audio survenant pendant la pause est écarté. Les périphériques virtuels conservent leurs identifiants, noms et formats.

Fermer l’éditeur laisse le routage, les effets, la capture et l’enregistrement fonctionner en arrière-plan. Sur macOS, fermer la fenêtre la masque ; quitter l’éditeur termine son processus. Sous Linux, fermer la fenêtre termine le processus de l’éditeur. Utilisez Ouvrir MixRelay dans le menu d’état pour revenir.

Quitter dans le menu d’état en arrière-plan arrête les périphériques et le bouclage et finalise les enregistrements. Rouvrir MixRelay restaure les périphériques enregistrés. Une pause globale enregistrée reste active jusqu’à la reprise ; les enregistreurs mis en pause manuellement ou arrêtés ne démarrent jamais du seul fait de reprendre tout l’audio.
