MIXRELAY / MANUAL

Stream Deck plug-in

Control graph nodes from Stream Deck on macOS.

Prerelease draft. Public downloads and purchases are not available yet. These instructions describe the current source build; installed behavior still needs verification in the environments noted below.

On this page

  • Requirements and setup
  • Keys, dials and recording

01

Requirements and setup

Requires macOS 14.2 or later, Stream Deck 6.6 or later and MixRelay running. Linux Stream Deck support is not provided. The plug-in uses a private local connection; no account, LAN pairing or public HTTP service is needed.

  1. When the official plug-in package is available, open its .streamDeckPlugin file with Stream Deck. A public download is not available yet.
  2. Add a MixRelay Power, Mute, Volume or Recording action.
  3. In the property inspector, choose the target graph and a node that supports that action.

Keep MixRelay background audio running. The editor window can be closed. A removed node must be reassigned explicitly. Commands that fail or disconnect are not queued for later playback.

02

Keys, dials and recording

Power turns node processing on or off. Mute silences its output while keeping processing. An off node must be powered on before other controls can act on it.

For Volume buttons, choose increase or decrease and a step of 0.5, 1, 2 or 3 dB. A Stream Deck + dial changes volume by the same step when rotated. Pressing the dial mutes if the target supports mute. Nodes without gain are not volume targets.

Recording lists recorder nodes only. Choose Record, Pause or Stop. Record resumes an existing paused take. The recording folder and format come from MixRelay’s recorder Options and are read-only in the property inspector.
