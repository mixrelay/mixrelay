MIXRELAY / MANUAL

Updates

Update MixRelay as one complete product. Updates are downloaded and installed manually.

Prerelease draft. Public downloads and purchases are not available yet. These instructions describe the current source build; installed behavior still needs verification in the environments noted below.

On this page

  • Check for a release
  • Install an update

01

Check for a release

Choose Check for updates in the app or status menu. MixRelay also checks at startup and every 24 hours. The app shows Installed and Latest release. No release has been published yet. means there is no public release; Could not check this product. Try again when online. means the check failed. Neither means the installation is up to date.

Use Check again when online. If a download is available, open its download action. MixRelay rechecks the catalog before opening the link. It does not install automatically.

02

Install an update

Save a .mix copy of important work. Quit recording and call apps, then run the new complete installer using the installation steps. On Linux, quit both the editor and background audio with the status menu’s Quit before updating; package hooks reject active MixRelay processes. On macOS, the installer requests that the app roles quit as part of installation.

Updates preserve devices, graphs, settings, recordings and authentication. There is one version and one installer for the editor and audio components. You do not choose separate Driver updates. Reopen MixRelay after installation and check the installed version.
