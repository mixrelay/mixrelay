MIXRELAY / MANUAL

System requirements and installation

Install the complete MixRelay product for your operating system. No separate Driver installation is needed.

Prerelease draft. Public downloads and purchases are not available yet. These instructions describe the current source build; installed behaviour still needs verification in the environments noted below.

On this page

  • Supported environments
  • Install on macOS
  • Gatekeeper checks
  • Install on Linux

01

Supported environments

  • macOS 15.0 or later, Apple Silicon or Intel. The installer is Universal 2. macOS 27 is the latest major version checked with an installed build.
  • Linux x86_64 or arm64, in a signed-in user session with PipeWire 1.2 or later and WirePlumber 0.5 or later. Current packages require glibc 2.39.

Linux build and code tests cover Debian 13, Ubuntu 26.04 and Kali rolling on both architectures, and Arch on x86_64. This does not confirm installation on every distribution. Unmodified Ubuntu 24.04 audio packages are too old. Normal Linux virtual machines are supported; Docker audio environments are unsupported. Windows is unsupported.

Intel Macs are supported on Apple-supported models running macOS 15–26. Each release is installed and checked on macOS 15 and 26 with Apple Silicon and Intel, and on macOS 27 with Apple Silicon. Not every patch version is checked.

02

Install on macOS

  1. When public downloads become available, get the official MixRelay-Installer-VERSION.pkg.
  2. Quit recording and call apps. Installation briefly interrupts system audio.
  3. Open the PKG. Read the App and Driver component agreements, then follow Installer’s Continue and Agree steps. Authorize installation with a macOS administrator account when asked.
  4. After installation, open /Applications/MixRelay/MixRelay.app. A restart is not required.

The package installs the editor, background audio, virtual devices and Uninstall MixRelay.app together. There is no component selection. Existing devices, graphs, settings, recordings and authentication are preserved.

03

Gatekeeper checks

Public macOS packages must be Developer ID signed and notarized. macOS may ask you to confirm opening downloaded software. If macOS reports an unidentified developer, an unverifiable package, damage or malware, stop and obtain a fresh official package or contact support. Do not disable Gatekeeper or remove quarantine attributes as an installation step. See Apple’s guidance on opening downloaded apps.

04

Install on Linux

Use your distribution’s package manager so it resolves dependencies. Replace the example filename with the downloaded package for your architecture.

sudo apt install ./MixRelay_VERSION_ARCH.deb
sudo dnf install ./MixRelay-VERSION-1.ARCH.rpm
sudo pacman -U ./mix-relay-VERSION-1-x86_64.pkg.tar.zst

Run only the command for your distribution. The package name is mix-relay. Launch MixRelay from your application menu as your normal user. PipeWire audio runs in that user’s session, never as root. You do not need an SDK or manual service setup. AppImage is not the supported installation or update path.
