MIXRELAY / MANUAL

MIDI controllers

Control nodes from a MIDI controller on macOS or Linux.

Prerelease draft. Public downloads and purchases are not available yet. These instructions describe the current source build; installed behaviour still needs verification in the environments noted below.

  • Assign a control
  • Volume and buttons
  • Devices and saved bindings

01

Assign a control

Use the small MIDI button at the right end of the editor header, Command+M on macOS or Ctrl+M on Linux to enter or leave MIDI map mode. Escape also leaves it. Highlighted controls on node cards are mapping targets: Power, Mute, Volume and recorder Record / resume, Pause and Stop. Click a control, or focus it and press Enter or Space, then move a MIDI control. The mapping is saved immediately. Another control replaces the mapping captured during the same selection. Select another target and use the same hardware control to add a second mapping. Exact duplicates keep their options. Only mapping targets are highlighted. The theme switch, graph editing controls and other on-screen commands are inactive; the MIDI switch and mappings panel remain available. Incoming MIDI never runs actions while map mode is on.

02

Volume and buttons

Note On with non-zero velocity or a CC rising across 64 triggers every matching button action once. Each Power or Mute target toggles from its own state. Absolute volume uses CC 0–127, with a default range of −60 to +12 dB; set Min/Max per mapping, including an inverted range. Pick-up waits until the fader reaches each target’s current level, including after an external edit or reconnection. Relative encoders use two’s complement or offset 64 and a separate step of 0.5, 1, 2 or 3 dB per mapping. Volume updates are combined per target at about 30 per second.

03

Devices and saved bindings

In map mode, the mappings panel replaces the graph list in the left sidebar. Leaving map mode restores the graph list. Mappings sharing a device, channel and Note/CC number appear under one hardware control. Each mapping has one selectable title with its graph, node and action, followed by its status, selected options and Remove. Select a title to open its graph, highlight its target and edit its volume options or recorder action. Delete/Backspace on a row or a mapped control removes only one mapping; a Remove button is also available. Missing targets retain their last known names. Undoing a node deletion restores its ID and mappings automatically. In the graph list, Command+Z on macOS or Ctrl+Z on Linux undoes a graph deletion; add Shift to redo. Deletion history lasts until the background process restarts. Saved mappings and restored graph identities survive restarts. Disconnected devices reattach automatically. Closing the editor ends map mode and resumes MIDI control.

MixRelay’s background process must stay running; the editor window can be closed. macOS uses CoreMIDI. Linux uses the ALSA sequencer (including ports exposed by PipeWire) and requires the ALSA library and sequencer access. MIDI unavailable shows the reason if access fails. MIDI is input only: there is no output, LED or motor-fader feedback, clock or BPM control.
