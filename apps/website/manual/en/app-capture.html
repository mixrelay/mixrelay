MIXRELAY / MANUAL

App audio capture

Capture a running application and route its audio through your graph.

Prerelease draft. Public downloads and purchases are not available yet. These instructions describe the current source build; installed behaviour still needs verification in the environments noted below.

On this page

  • Select an application
  • Missing audio and source playback

01

Select an application

  1. Open the source app and start playback so an audio source is available.
  2. In MixRelay, choose Add node → Source and select the app under Running applications.
  3. Connect its output channels to a processor, output or recorder. Adjust Source gain in Options as needed.

The source list contains discovered apps, not individual browser tabs or windows. A display-name change does not change which app is captured. Physical input and individual app capture nodes share the free edition’s two-input limit.

02

Missing audio and source playback

Capture requires 48 kHz and the relevant macOS permission. If a node is Offline, check that the app is running. If Select the application again appears, use the node’s application selection to choose the intended source. MixRelay does not choose a replacement when several sources match.

The app’s original playback and the MixRelay route can both affect what you hear. Check your monitoring routes if audio sounds doubled. MixRelay does not change the system default output. Source suppression, where used by the capture route, applies only to the path MixRelay owns; the current UI has no separate source-playback toggle.
