MIXRELAY / MANUAL

External plug-ins

Install effects with their vendor’s installer, then discover them in MixRelay.

Prerelease draft. Public downloads and purchases are not available yet. These instructions describe the current source build; installed behaviour still needs verification in the environments noted below.

On this page

  • Formats by platform
  • Find and use an effect
  • Scan, editor and format errors

01

Formats by platform

  • macOS: VST3, CLAP, AU and AUv3.
  • Linux: VST3, CLAP and LV2.

The list contains audio effects that pass discovery and layout checks. Instrument and MIDI workflows are not provided. A supported format does not guarantee that every plug-in, architecture or channel layout will work. The free edition allows two external plug-in instances, including instances that are off. The number of discovered effects is unrestricted.

02

Find and use an effect

  1. Install the plug-in for your platform and architecture using its vendor’s instructions.
  2. In Add node → Processor, choose Rescan audio effects. For a custom VST3, CLAP or LV2 location, choose Add plug-in folder….
  3. Select a discovered effect directly in the Processor menu. Its description identifies its format and vendor. Review Channel layout and connect the required main, sidechain or auxiliary ports.
  4. Use the node’s Options for exposed parameters. A new plug-in node opens its native editor once when available. Use Open to reopen it.

Linux native editors require X11 or XWayland. A missing editor does not create a generic native window. Use exposed parameters when available.

03

Scan, editor and format errors

If Effect search incomplete appears, open Scan issues and Technical details. Previously available effects remain listed when a scan stage fails. Correct the installation or folder and use Retry or rescan.

For a crashed plug-in, use Retry crashed plug-in: … if offered. If an editor is unavailable, read its specific reason, such as no native editor or missing X11/XWayland. Some AU/VST/LV2 sessions reject live format changes because native preset-state transfer is not implemented. The current session is retained; do not assume the requested format was applied.
