MIXRELAY / MANUAL

Uninstalling

Remove the complete product with its uninstaller or Linux package manager.

Prerelease draft. Public downloads and purchases are not available yet. These instructions describe the current source build; installed behavior still needs verification in the environments noted below.

On this page

  • Before removal
  • Remove on macOS
  • Remove on Linux

01

Before removal

Save any work you need as a .mix file. Stop recording and quit call and recording apps. If you want to release this computer’s paid activation, use Deactivate this device while online before removal. Uninstalling does not confirm server-side deactivation.

02

Remove on macOS

  1. Open /Applications/MixRelay/Uninstall MixRelay.app.
  2. Leave Delete saved MixRelay settings unchecked to keep virtual-device settings.
  3. Choose Remove MixRelay and approve the macOS administrator request. The current removal dialog uses these Driver labels but removes the complete product.
  4. Wait for confirmed completion. Removal stops devices and loopback and briefly interrupts system audio.

The optional deletion removes saved device settings only. Graphs, recordings, exported work and paid authentication remain on macOS. Moving the editor app to Trash alone does not remove the installed audio components. If removal fails, read the message and check the current installation before retrying; some components may already be gone. Cancelling authorization leaves the product unchanged.

03

Remove on Linux

Quit the editor and choose Quit in the background status menu. Open the installed Uninstall MixRelay application entry as your normal user. Keep the saved-graphs-and-settings deletion option unchecked to preserve those files. The remover uses the session’s normal polkit authentication agent and package manager. Successful removal clears the local paid-license sign-in; recordings and exported projects remain.

You can instead remove the mix-relay package directly. Choose only your distribution’s command. Direct package-manager removal preserves per-user settings and local authentication.

sudo apt remove mix-relay
sudo dnf remove mix-relay
sudo pacman -R mix-relay

If authorization cannot appear, check that your desktop session has a polkit authentication agent. If the app was removed but cleanup failed, follow the displayed recovery message. Do not delete unrelated audio services or user folders.
