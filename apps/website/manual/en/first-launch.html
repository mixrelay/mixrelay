MIXRELAY / MANUAL

First launch and permissions

Open MixRelay, wait for its audio engine, then select the sources you want to use.

Prerelease draft. Public downloads and purchases are not available yet. These instructions describe the current source build; installed behavior still needs verification in the environments noted below.

On this page

  • Connect to the audio engine
  • macOS audio capture and microphone
  • Make your first route

01

Connect to the audio engine

Connecting to MixRelay appears while audio is prepared. If MixRelay is required appears, install the complete product. If Update MixRelay appears, update the installed product. For Cannot connect to MixRelay, choose Retry connection after checking the installation.

The free edition requires no purchase activation. The app uses the first supported OS language preference and falls back to English. Appearance offers System, Light and Dark.

02

macOS audio capture and microphone

When you first use an application source, macOS can request permission to capture application or system audio. When you use a microphone or another physical audio input, macOS can request microphone access. Allow the requested access if you want to use that source. These are separate permissions; microphone approval alone does not enable application capture.

If access was denied, open System Settings → Privacy & Security. Check the audio capture control under Screen & System Audio Recording and check Microphone for physical inputs. Labels and prompts vary by macOS version. Enable access for the MixRelay entry responsible for the request and follow any macOS restart instruction. Then retry the source in MixRelay. See Apple’s screen and system audio permission guide.

On Linux, sources use the normal PipeWire session. A macOS-style permission prompt is not part of this flow.

03

Make your first route

  1. Select an existing graph, or choose New graph, enter a Graph name and choose Create if none exists. The free edition allows one graph.
  2. Use Add node → Source to choose a running app or an audio input.
  3. Use Add node → Output to choose an audio output. Connect each source output channel to an input channel on the output node.
  4. Play audio in the source app or speak into the input. Check the meters and output device.

To send the mix to OBS or a DAW, use MixRelay IO as a virtual output and select it as the input in the receiving app.
