MIXRELAY / MANUAL

Routing workspace

Build a graph from source, processor and output nodes. Cables carry audio between individual channels.

Prerelease draft. Public downloads and purchases are not available yet. These instructions describe the current source build; installed behavior still needs verification in the environments noted below.

On this page

  • Graphs, nodes and saving
  • Connect and map channels
  • Connect without dragging
  • Off, Mute, Bypass, Pause and exit

01

Graphs, nodes and saving

Use New graph to create a graph and Add node for Source, Processor or Output. Select a graph in Graphs to edit it. Selection does not turn other graphs off. Licensed graphs can run together.

Open a node’s Options for its available parameters. Double-click its name, press F2 on a focused node, or use Rename display name in its menu. A display name changes this node only. Clear it to restore the original name.

Edits and layout are saved automatically. A save warning means they may be lost after restart. For a portable workspace, use File → Save or Save As… to write a .mix file. New Workspace and Open… ask before replacing current contents. A workspace file does not install missing devices or plug-ins.

02

Connect and map channels

Drag an output port to an input port. For a stereo pair, connect both channels. Hold Shift to select more output channels on the same node, then drag the selection to the destination’s first channel. The destination channel offset is preserved. Press Escape to cancel and clear the channel selection.

Right-click a cable for Delete cable. A port menu offers Disconnect channel or Disconnect selected channels. Select a node or cable and press Delete or Backspace to remove it. Fit graph brings the graph into view. Use Command+Z on macOS or Ctrl+Z on Linux to undo graph edits; add Shift to redo.

Delete graph stops that graph’s audio and recordings. Graph deletion cannot be undone; saved workspace files remain.

03

Connect without dragging

  1. Use Tab to focus the source node. Enter or Space selects it. Arrow keys move the selected node; hold Shift for larger steps.
  2. Press Shift+F10 or the Context Menu key and choose Connect channels….
  3. Choose First output channel and Number of channels, or keep an existing channel selection. Choose Destination and First input channel.
  4. Read Preview, including skipped connections and their reasons. Choose Connect, or Cancel to leave the graph unchanged.

The same context-menu keys work on a focused cable or the canvas. Controls inside a node keep their own keyboard behavior. Escape closes menus and dialogs.

04

Off, Mute, Bypass, Pause and exit

  • A node’s power control disables processing and blocks its signal when off.
  • Mute keeps processing and silences the node’s output.
  • An effect’s Bypass passes dry audio while retaining its settings.
  • Pause in the footer or status menu pauses all graphs and active recordings. Resume uses current audio. Paused audio is discarded. Virtual devices keep their IDs, names and formats.

Closing the editor keeps routing, effects, capture and recording running in the background. On macOS, closing the window hides it; quitting the editor ends the editor process. On Linux, closing the window ends the editor process. Use Open MixRelay in the status menu to return.

Quit in the background status menu stops devices and loopback and finalizes recordings. Reopening MixRelay restores the saved devices. A saved global pause remains until you resume; manually paused or stopped recorders never start merely because you resume all audio.
