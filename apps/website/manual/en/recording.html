MIXRELAY / MANUAL

Recording

Record any connected graph signal to an RF64 WAV file.

Prerelease draft. Public downloads and purchases are not available yet. These instructions describe the current source build; installed behavior still needs verification in the environments noted below.

On this page

  • Set up and record
  • Pause and finish a take
  • Free and technical limits

01

Set up and record

  1. Choose Add node → Output → Recorder. Connect the channels you want to record.
  2. Open Options. Set Channels and use Choose folder… for the Recording folder.
  3. Choose WAV sample rate (Input rate follows the input when starting a take) and Bit depth: PCM16, PCM24 or Float32.
  4. Choose Record. MixRelay creates the take’s filename. Use Pause, Resume and Stop as needed.

Stop before changing the recording settings. Recording and paused takes lock those settings. Each take is one RF64 .wav file, including files larger than 4 GiB. Use a reader that supports RF64. MixRelay does not split the take by size or offer MP3 recording.

02

Pause and finish a take

Resume continues in the same file. A paused interval adds no silence: record 10 seconds, pause for 5 seconds, then record 10 seconds to create a 20-second file. Recorded time counts the audio written to the file.

Global Pause also pauses active recorders. Global Resume does not restart a recorder paused manually or already stopped. You can use the recorder’s Stop during a global pause to finish the file. Stop finalizes the WAV header. Closing the editor keeps recording; quitting background audio finishes open recordings.

03

Free and technical limits

Free recording allows one recorder, up to two channels and two hours of recorded audio per take. Paused time is excluded. At the limit, the file finishes normally and audio routing continues. A paused take still occupies the recorder allowance.

The licensed engine supports 1–8 channels per recorder and up to 16 recording sessions. The time allowance is fixed when a take starts. Activating later does not extend a free take; license expiry does not cut short a take started with paid access. Start a new take to use the current license allowance.

If Recording error appears, check the chosen folder, write access and available disk space. Stop and check the saved file before starting another take.
