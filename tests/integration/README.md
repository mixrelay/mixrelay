# Integration validation

The first hardware/application matrix covers buffer sizes 32 through 16384,
48 kHz then 44.1 kHz, stop/start, sleep/wake, hotplug, ring wrap, multiple
readers, Capture and Stream together, OBS restart, CPU pressure, USB and
Bluetooth devices, and major conferencing/browser applications.

Long-running validation records underruns, overruns, CPU use, memory use, and
measured latency under identical conditions.
