# Tray menu polish — 2026-09-10

- Preserved the supplied brand artwork and embedded 64px template tray icon.
- Native tray labels follow the resolved UI language (Korean or English), including
  language changes. Browser-only rendering does not invoke native commands.
- A disabled `MixRelay` title appears once at the top, followed by a separator and
  the two actions. Namespaced tray actions do not overlap workspace actions.
- Open restores a minimized/hidden main window before focusing it.
- On macOS, closing the main window switches activation policy to Accessory only
  after hide succeeds; Open restores Regular before showing/focusing. Application
  Reopen uses the same path. Auxiliary windows retain their normal close behavior.
- Labels are concise actions only: `열기` / `종료`, or `Open` / `Quit`, without
  repeating the product name. The existing desktop-only exit behavior remains;
  this change does not shut down the independent engine service.
- No duplicate Quit shortcut: the application menu retains its existing shortcut.

The command's State argument uses a narrow needless-pass-by-value allowance because
Tauri injects State by value and cannot inject a borrowed State. Locale itself is
borrowed; no dependencies, unsafe code, or audio-thread work were added.
Restore errors are emitted through tracing, but persistent logging is not verified.
This is UI polish, not a performance optimization; no performance claim is made.
Windows/Linux native rendering was not tested. No release or push was performed.
