## Rawsector manual language policy

Write and translate manuals for Rawsector only in languages the site supports. Adding an app language does not automatically add a website manual language.

Before writing or translating, compare the planned languages with the site's current language selector. Confirm the exact locale codes accepted by the CMS before writing translations. A document's translation selector lists existing translations and cannot establish which languages the site supports.

Do not create website manual drafts, translation files or CMS translations in unsupported languages or languages whose support has not been confirmed. Do not substitute another locale code or treat a page that falls back to the default language as a translation. Add a manual language only after the site supports it.

Site support alone does not authorize translating every language. Keep the translation set within the current task's scope. Before publishing, check that every planned locale is supported and that its body, contents, captions and links display in the intended language. Report existing translations outside the supported set and identify what needs attention; do not delete them as part of an unrelated edit.

This policy applies to Rawsector website manuals and materials prepared for their publication. App UI and other distribution channels follow their own language requirements.
